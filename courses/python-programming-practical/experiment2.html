Practical No. 02

Swap the Values of Two Variables Using a Temporary Variable

1. Aim

To write a Python program to swap the values of two variables using a temporary variable.

2. Learning Objectives

After completing this practical, students will be able to:

  • Understand the concept of variables.
  • Learn how values are stored in variables.
  • Use a temporary variable to interchange values.
  • Display output using the print() function.
  • Understand the sequence of assignment statements.

3. Theory

Swapping means exchanging the values of two variables. It is one of the most fundamental programming operations and is widely used in sorting algorithms, searching techniques, and many other applications.

In this method, a third variable called a temporary variable is used to store the value of one variable while the values are exchanged.

Suppose two variables contain the following values: 


num1 = 15
num2 = 25

To swap these values without losing the original value of num1, a temporary variable is used: 


temp = num1
num1 = num2
num2 = temp

The sequence of assignment statements is important. First, the original value of num1 is safely stored in temp. Then the value of num2 is assigned to num1. Finally, the original value of num1, which is stored in temp, is assigned to num2.

4. Algorithm

  1. Start the program.
  2. Accept two numbers from the user.
  3. Store the value of the first variable in a temporary variable.
  4. Assign the value of the second variable to the first variable.
  5. Assign the value stored in the temporary variable to the second variable.
  6. Display the swapped values.
  7. Stop the program.

6. Program

Python Program — Swap Two Variables Using a Temporary Variable 


# Practical No. 2
# Swap two variables using a temporary variable

# Input from the user
num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

print("\nBefore Swapping")
print("First Number =", num1)
print("Second Number =", num2)

# Swapping using temporary variable
temp = num1
num1 = num2
num2 = temp

print("\nAfter Swapping")
print("First Number =", num1)
print("Second Number =", num2)

7. Program Explanation

Step 1 — Accept Input 


num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

The input() function accepts values from the user. Since input() returns a string, the int() function is used to convert the entered values into integers.

Step 2 — Display the Original Values 


print("\nBefore Swapping")
print("First Number =", num1)
print("Second Number =", num2)

These statements display the values of both variables before swapping.

Step 3 — Store the First Value in a Temporary Variable 


temp = num1

The value stored in num1 is copied into temp. This protects the original value of num1 from being lost.

Step 4 — Assign the Second Value to the First Variable 


num1 = num2

The value stored in num2 is assigned to num1.

Step 5 — Assign the Temporary Value to the Second Variable 


num2 = temp

The original value of num1, which was stored safely in temp, is now assigned to num2.

Step 6 — Display the Swapped Values 


print("\nAfter Swapping")
print("First Number =", num1)
print("Second Number =", num2)

Finally, the program displays the values after swapping.

10. Key Points to Remember

  • A variable is a name used to store a value.
  • A temporary variable can be used as an intermediate storage location.
  • The original value must be stored before it is overwritten.
  • The order of assignment statements is important during swapping.
  • The print() function is used to display values and messages.

11. Result

Thus, the Python program to swap the values of two variables using a temporary variable was successfully executed, and the values of the two variables were interchanged.
