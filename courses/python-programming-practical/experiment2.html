Practical 02 — Swap the Values of Two Variables

Practical 02

Swap the Values of Two Variables

Course : Python Programming

Practical No. : 02

1. Aim

To write a Python program that swaps the values of two variables without using a third (temporary) variable, using different techniques

4.1 The "Swap" Problem

Given two variables x and y, after swap, x should hold the original value of y, and y should hold the original value of x.

The naïve attempt in any language is: 

x = 10
y = 25
x = y          # x now holds 25 — original 10 is LOST
y = x          # y also becomes 25
# Result: x = 25, y = 25  ❌  — swap failed!

Python, like every other programming language, evaluates the right-hand side first and then assigns that resulting value to the variable on the left (Ekmekci et al., 2016). The original value of x gets overwritten before we ever had a chance to read it. Hence a naive two-line swap is doomed — we need some auxiliary structure (temporary variable, arithmetic, packing, or XOR) to remember the original.

Program 2A — Using a Temporary Variable 🟢 

"""
Program 2A: Swap two integers EXPLICITLY (using a temp variable).
This is the textbook "three-glass" swap — easy to read, easy to debug.
"""

# Read input
x = int(input("Enter first number  (x): "))
y = int(input("Enter second number (y): "))

print(f"\nBefore swap → x = {x}, y = {y}")

# Swap using a temporary variable
temp = x         # remember x
x    = y         # x becomes old y
y    = temp      # y becomes remembered old x

print(f"After  swap → x = {x}, y = {y}")

Sample Run 

Enter first number  (x): 10
Enter second number (y): 25

Before swap → x = 10, y = 25
After  swap → x = 25, y = 10

Program Explanation

The program uses a temporary variable to safely exchange the values of two variables.

  • temp = x — stores the original value of x.
  • x = y — assigns the original value of y to x.
  • y = temp — assigns the original value of x, stored in temp, to y.

This approach prevents the original value of x from being lost during the swap.

Step-by-Step Working

Step Statement x y temp
Initial Input values 10 25 —
1 temp = x 10 25 10
2 x = y 25 25 10
3 y = temp 25 10 10

Observation

The values of two variables are successfully exchanged using a temporary variable.

For the input values x = 10 and y = 25, the final values after swapping are x = 25 and y = 10.

Important Point

The temporary variable approach is simple, readable, and easy to understand. However, the aim of this practical is to explore different techniques for swapping values, including approaches that do not require a third variable.
