Practical No. 2

Aim: To write a Python program to swap the values of two variables using a temporary variable.

Learning Objectives

After completing this practical, students will be able to:

  • Understand the concept of variables.
  • Learn how values are stored in variables.
  • Use a temporary variable to interchange values.
  • Display output using the print() function.
  • Understand the sequence of assignment statements.

Theory

Swapping means exchanging the values of two variables. It is one of the most fundamental programming operations and is widely used in sorting algorithms, searching techniques, and many other applications.

In this method, a third variable called a temporary variable is used to store the value of one variable while the values are exchanged.

Key Concept: The temporary variable acts as a safe storage location so that the original value of the first variable is not lost during the swapping process.

Algorithm

  1. Start the program.
  2. Accept two numbers from the user.
  3. Store the value of the first variable in a temporary variable.
  4. Assign the value of the second variable to the first variable.
  5. Assign the value stored in the temporary variable to the second variable.
  6. Display the swapped values.
  7. Stop the program.

Program

# Practical No. 2
# Swap two variables using a temporary variable

# Input from the user
num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

print("\nBefore Swapping")
print("First Number =", num1)
print("Second Number =", num2)

# Swapping using temporary variable
temp = num1
num1 = num2
num2 = temp

print("\nAfter Swapping")
print("First Number =", num1)
print("Second Number =", num2)

Program Explanation

The program first accepts two numbers from the user and stores them in num1 and num2.

Before swapping, the values of both variables are displayed.

The swapping is performed using three assignment statements:

1. temp = num1

The value of num1 is copied into the temporary variable temp.


2. num1 = num2

The value of num2 is assigned to num1.


3. num2 = temp

The original value of num1, which was stored safely in temp, is assigned to num2.

Sample Output

Result

Thus, the Python program to swap the values of two variables using a temporary variable was successfully executed.
