Python Programming Practical

Laboratory Course

Course Overview

This laboratory course provides hands-on experience in Python programming through practical problem-solving exercises. Students will learn Python syntax, functions, strings, lists, recursion, algorithms, and mini-project development while improving logical thinking and programming skills.

Pre-requisites

  • Basic knowledge of C or C++ Programming.
  • Basic computer operating skills.
  • Understanding of programming fundamentals.
  • Interest in problem solving using Python.

Course Objectives

  • Understand variables and Python data types.
  • Develop problem-solving skills using Python.
  • Implement programs using lists, strings, dictionaries and functions.
  • Develop practical programming skills through laboratory exercises.
  • Prepare students for advanced Python applications.

Course Outcomes

  • CO1: Understand the importance of Python Programming.
  • CO2: Develop skills to implement Python programs.
  • CO3: Gain practical programming experience.
  • CO4: Apply standard programming constructs for software development.

Laboratory Guidelines

  • Read the problem statement before writing the program.
  • Write clean, well-indented, and properly commented Python code.
  • Test your program with different input values before submission.
  • Record the algorithm, source code, output, and conclusion in the laboratory journal.
  • Follow good programming practices and maintain academic integrity.
