Practical No. 03

Find the Largest Number Among Three in Python

1. Aim

To write Python programs that determine the largest of three numbers entered by the user using different techniques such as nested if-else statements and the if-elif-else ladder. The practical also helps compare these approaches in terms of readability, simplicity, and efficiency.

2. Algorithm

2.1 Algorithm — Nested if-else Method

  1. Start.
  2. Read three numbers x, y, and z from the user.
  3. Compare x with y.
  4. If x is greater than or equal to y:
  5. Compare x with z.
  6. If x is greater than or equal to z, then x is the largest.
  7. Otherwise, z is the largest.
  8. Otherwise (y is greater than x):
  9. Compare y with z.
  10. If y is greater than or equal to z, then y is the largest.
  11. Otherwise, z is the largest.
  12. Display the largest number.
  13. Stop.

2.2 Algorithm — if-elif-else Ladder Method

  1. Start.
  2. Read three numbers x, y, and z from the user.
  3. If x is greater than or equal to both y and z, display x as the largest.
  4. Else if y is greater than or equal to both x and z, display y as the largest.
  5. Otherwise, display z as the largest.
  6. Stop.

4. Program Codes

Program 3A — Find the Largest Number Using Nested if-else 


"""
Program 3A
Find the largest of three numbers using nested if-else.
"""

x = float(input("Enter first number (x): "))
y = float(input("Enter second number (y): "))
z = float(input("Enter third number (z): "))

print("\nYou entered:")
print("x =", x)
print("y =", y)
print("z =", z)

if x >= y:
    if x >= z:
        largest = x
        variable = "x"
    else:
        largest = z
        variable = "z"
else:
    if y >= z:
        largest = y
        variable = "y"
    else:
        largest = z
        variable = "z"

print("\nThe largest number is", largest)
print("Stored in variable", variable)

Program 3B — Find the Largest Number Using if-elif-else Ladder 


"""
Program 3B
Find the largest of three numbers using the if-elif-else ladder.
"""

x = float(input("Enter first number (x): "))
y = float(input("Enter second number (y): "))
z = float(input("Enter third number (z): "))

print("\nYou entered:")
print("x =", x)
print("y =", y)
print("z =", z)

if x >= y and x >= z:
    largest = x
    variable = "x"
elif y >= x and y >= z:
    largest = y
    variable = "y"
else:
    largest = z
    variable = "z"

print("\nThe largest number is", largest)
print("Stored in variable", variable)

Sample Output (Tie Case) 


Enter first number (x): 50
Enter second number (y): 50
Enter third number (z): 30

You entered:
x = 50.0
y = 50.0
z = 30.0

The largest number is 50.0
Stored in variable x

Note: When two or more numbers are equal and are the largest, the first matching condition is executed. In the above example, both x and y are equal, but x is displayed because it satisfies the first if condition.

5. Comparison of the Two Methods

Nested if-else if-elif-else Ladder
Uses one if statement inside another. Uses a sequence of if, elif, and else statements.
Suitable for solving problems with multiple levels of decisions. Suitable when checking several conditions one after another.
Can become difficult to read if deeply nested. More readable and easier to understand.
Requires careful indentation. Simpler program structure.
Produces the same result. Produces the same result.

6. Key Points to Remember

  • The program compares three numbers to determine the largest value.
  • Both nested if-else and if-elif-else ladder methods produce the same result.
  • The comparison operator >= is used so that equal values are also handled correctly.
  • The if-elif-else ladder is generally easier to read and maintain.
  • Python uses indentation to define blocks of code.

7. Result

Thus, Python programs to find the largest of three numbers using both the nested if-else method and the if-elif-else ladder method were successfully executed. The programs correctly identified the largest number entered by the user.
