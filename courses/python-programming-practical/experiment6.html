Practical No. 06

Display a Multiplication Table Using Functions in Python

1. Aim

To write a Python program using a user-defined function to display the multiplication table of a given number.

2. Theory

What is a Function?

A function is a reusable block of code designed to perform a specific task. Functions help to organize programs and avoid writing the same code repeatedly.

In Python, a function is defined using the def keyword. 


def function_name(parameters):
    # statements

Parameters and Return Values

A function can receive values through parameters. It can also send a result back to the calling program using the return statement.

In this practical, the function receives a number and generates its multiplication table using a for loop.

Using a for Loop

The for loop is used to repeat the multiplication operation for a sequence of numbers. The range() function generates the required sequence. 


for i in range(1, 11):
    print(n * i)

3. Multiplication Table

Consider the number: 


n = 7

Its multiplication table from 1 to 10 is: 


7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
7 × 5 = 35
7 × 6 = 42
7 × 7 = 49
7 × 8 = 56
7 × 9 = 63
7 × 10 = 70

Instead of writing ten separate multiplication statements, we can use a for loop inside a user-defined function.

4. Algorithm

  1. Start.
  2. Define a function multiplication_table(n, upto=10).
  3. Use a for loop from 1 to upto.
  4. Calculate and display n × i.
  5. Read the number from the user.
  6. Call the multiplication_table() function.
  7. Stop.

5. Program Codes

Program A — Using a Default Parameter

The following program displays the multiplication table from 1 to 10 using a user-defined function. 


# Program 6A
# Display a multiplication table using a function

def multiplication_table(n, upto=10):

    for i in range(1, upto + 1):

        print(f"{n} × {i} = {n * i}")


# Main program
num = int(input("Enter a number: "))

multiplication_table(num)

Output 


Enter a number: 7

7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
7 × 5 = 35
7 × 6 = 42
7 × 7 = 49
7 × 8 = 56
7 × 9 = 63
7 × 10 = 70

Explanation

The function: 


def multiplication_table(n, upto=10):

has two parameters:

  • n — the number whose multiplication table is required.
  • upto=10 — a default parameter that specifies the table limit as 10.

The statement: 


range(1, upto + 1)

generates numbers from 1 to 10 when the default value of upto is used.

The expression: 


f"{n} × {i} = {n * i}"

uses an f-string to display the multiplication operation and its result in a formatted manner.

6. Key Points

Concept Description
n Parameter that receives the number for the multiplication table.
num Argument passed to the function.
upto=10 Default parameter. The table is displayed up to 10 by default.
range(1, upto + 1) Generates the sequence from 1 to the specified limit.
for loop Repeats the multiplication operation.
f-string Formats the multiplication expression and result for display.

7. Program B — Using a User-Defined Multiplication Limit

The function can also accept a second argument so that the user can decide how far the multiplication table should be displayed. 


# Program 6B
# Display a multiplication table up to a user-defined limit

def multiplication_table(n, upto=10):

    for i in range(1, upto + 1):

        print(f"{n} × {i} = {n * i}")


# Main program
num = int(input("Enter a number: "))

limit = int(input("Enter the multiplication limit: "))

multiplication_table(num, limit)

Output 


Enter a number: 8
Enter the multiplication limit: 5

8 × 1 = 8
8 × 2 = 16
8 × 3 = 24
8 × 4 = 32
8 × 5 = 40

Explanation

In this program, two values are entered by the user: 


num
limit

The function is called using: 


multiplication_table(num, limit)

Here, num is passed to parameter n, while limit is passed to parameter upto.

Therefore, the function displays the multiplication table only up to the limit entered by the user.

8. Understanding the Function Call

Suppose the user enters: 


Enter a number: 8
Enter the multiplication limit: 5

The function call is: 


multiplication_table(8, 5)

Therefore:

Parameter Value
n 8
upto 5

The loop then executes: 


i = 1
i = 2
i = 3
i = 4
i = 5

and produces the multiplication table from 1 to 5.

9. Important Statements

Function Definition 


def multiplication_table(n, upto=10):

Defines a function named multiplication_table with two parameters.

for Loop 


for i in range(1, upto + 1):

Repeats the statements for each value from 1 to the specified multiplication limit.

Multiplication 


n * i

Calculates the product of the given number and the current loop value.

Function Call 


multiplication_table(num)

Calls the function using the number entered by the user.

Function Call with Two Arguments 


multiplication_table(num, limit)

Calls the function and specifies the multiplication limit.

10. Result

The Python program to display a multiplication table was successfully implemented using a user-defined function, parameters, default parameters, for loop, range() function, and formatted output.

11. Conclusion

In this practical, we learned how to define and call a user-defined function in Python.

We also learned how to pass arguments to a function, use a default parameter, repeat operations using a for loop, and display formatted output using an f-string.

The practical also demonstrated how the same function can be reused with different multiplication limits.
