Practical No. 09

Generate Possible Words from Given Characters

1. Aim

To write a Python program that generates all possible arrangements of a given set of characters and, optionally, filters them down to real words using a small dictionary.

2. Prerequisites

Strings as iterable sequences · for loops and nested loops · def and return · set · "".join · import of a standard-library module.

3. Learning Outcomes

After this practical, students can:

  1. Explain what a permutation is and why generating words is a permutation problem.
  2. Use itertools.permutations(chars, r) to get every ordering of r characters.
  3. Turn each tuple of characters into a string with "".join.
  4. Use a set to remove duplicates automatically (important when letters repeat).
  5. Filter candidates against a dictionary to separate valid words from mere arrangements.

4. Theory

If you are given the characters c, a, t, the question "what words can I make?" is really the question "in how many orders can I arrange these letters?" — that is a permutation.

  • For n characters taken r at a time, the number of arrangements is n! / (n − r)!. For cat (n = 3), taking all 3 gives 3! = 6 arrangements; taking 2 at a time gives 3!/1! = 6.
  • itertools.permutations(chars, r) yields every ordering as a tuple of length r, so the program never needs nested loops of unknown depth: 
from itertools import permutations

list(permutations("cat", 2))

# [('c','a'), ('c','t'), ('a','c'),
#  ('a','t'), ('t','c'), ('t','a')]

Two details do most of the work:

  • "".join(combo) converts the tuple ('c','a','t') into the string "cat".
  • set stores the results, so when a letter repeats (as in aab) the duplicate arrangements collapse automatically — no manual checking needed.

Finally, not every arrangement is a word. atc is a valid arrangement of cat but not an English word, so a dictionary filter (if word in dictionary) is what turns a list of candidates into a list of words.

5. Algorithm

  1. Start.
  2. Read the characters from the user; remove spaces and convert to lower case.
  3. If no characters were given, print a message and stop.
  4. Import permutations from itertools.
  5. For each length r from min_len to max_len:
    • Generate every ordering of r characters with permutations(chars, r).
    • Join each tuple into a string and add it to a set (duplicates removed automatically).
  6. Convert the set to a sorted list — the candidates.
  7. Compare each candidate with the words in the dictionary; keep only the matches.
  8. Print the number of candidates, the candidate list, and the valid words found.
  9. Stop.

6. Program

"""Practical 9 - Generate possible words from given characters."""

from itertools import permutations


def generate_candidates(chars, min_len=2, max_len=None):
    """Return a sorted list of unique strings built from the given characters.

    min_len : shortest string to generate (default 2)
    max_len : longest string to generate (default = number of characters)
    """

    if not chars:
        return []

    chars = list(chars)                              # e.g. ['c', 'a', 't']

    max_len = max_len if max_len is not None else len(chars)

    max_len = min(max_len, len(chars))

    candidates = set()                               # set removes duplicates

    for r in range(min_len, max_len + 1):

        for combo in permutations(chars, r):         # every ordering of r chars

            candidates.add("".join(combo))           # tuple -> string

    return sorted(candidates)


def filter_valid(candidates, dictionary):
    """Keep only the candidates that appear in the dictionary."""

    valid = {word.lower() for word in dictionary}

    return [word for word in candidates if word in valid]


# ------------------------------ main program ------------------------------

chars = input("Enter characters (e.g. cat): ").replace(" ", "").lower()


if not chars:

    print("No characters given.")

else:

    DICTIONARY = {
        "at",
        "act",
        "cat",
        "car",
        "arc",
        "ant",
        "an"
    }

    candidates = generate_candidates(chars, min_len=2)

    words = filter_valid(candidates, DICTIONARY)

    print(f"\nCharacters      : {list(chars)}")

    print(f"Candidates ({len(candidates)}) : {candidates}")

    print(f"Real words ({len(words)})  : {words}")

7. Sample Output

Enter characters (e.g. cat): cat

Characters      : ['c', 'a', 't']
Candidates (12) : ['ac', 'act', 'at', 'atc', 'ca', 'cat',
                   'ct', 'cta', 'ta', 'tac', 'tc', 'tca']
Real words (3)  : ['act', 'at', 'cat']
Enter characters (e.g. cat): aab

Characters      : ['a', 'a', 'b']
Candidates (6)  : ['aa', 'aab', 'ab', 'aba', 'ba', 'baa']
Real words (0)  : []

In the second run the repeated a produces duplicate arrangements (for example aab arises twice); the set keeps only one copy, so 6 unique strings survive instead of the 9 raw tuples.

8. Edge Cases

Input Result Why
"" (nothing entered) "No characters given." Guard clause stops the program early
"a" no candidates A single character has no arrangement of length ≥ 2
"cat" 12 candidates 3P2 = 6 and 3P3 = 6
"aab" 6 candidates The set collapses repeated arrangements
"abc" 12 candidates All characters distinct, so no collisions
"cat" with min_len=1 includes a, c, t Short words appear only when allowed by min_len
10 distinct characters, all lengths 10! arrangements at the full length alone Factorial growth — see the warning below

⚠️ Performance warning: the count of arrangements grows factorially. Ten distinct characters taken all at length gives 10! = 3,628,800 arrangements, so keep the input short (3–6 characters) in the lab, or restrict max_len.

9. Exercises

  1. Let the user choose min_len and max_len at run time.
  2. Print the candidates grouped by length using a dictionary of lists.
  3. Write a version that generates arrangements of exactly one length r (remove the outer loop).
  4. Extend filter_valid so it also reports how many candidates were rejected as non-words.

10. Viva Questions

  1. What is a permutation, and how many arrangements does n characters taken r at a time give? (n! / (n − r)!)
  2. What does permutations("cat", 2) return — strings or tuples?
  3. What is the job of "".join(combo)?
  4. Why is a set used instead of a list while collecting candidates?
  5. What happens to the number of unique results when a character repeats, and why?
  6. Why is atc a candidate but not a real word?
  7. Why is sorted applied before displaying the results?
  8. Why is itertools.permutations preferred over three nested loops for this problem?

Teacher's note: The idea to land is that "generating words" is two separate jobs — enumerate every ordering (a permutation task, handled in one line by itertools), then decide which orderings are words (a lookup task). Keep the dictionary small and the input at three or four letters, and the factorial growth never becomes a problem in class.
