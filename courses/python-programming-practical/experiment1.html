Practical No. 01

Calculate the Area of a Triangle in Python

1. Aim

To write a Python program that calculates the area of a triangle using different formulas and approaches, demonstrating the use of variables, input, type conversion, operators, conditional statements, the math module, and user-defined functions.

2. Prerequisites

Before starting this practical, the student should be comfortable with:

  • Variables and assignment (= vs ==) — covered in Theory Session 1.
  • input always returns a string — covered in Theory Session 2.
  • Type conversion — int, float.
  • Arithmetic operators — +, -, *, /, **.
  • Basic if-else.

3. Algorithm

For ½ × b × h version

  1. Start the program.
  2. Import the math module (optional, not strictly required here).
  3. Prompt the user to enter the base of the triangle.
  4. Read the value and convert to float.
  5. Prompt the user to enter the height.
  6. Read the value and convert to float.
  7. Compute area = 0.5 * base * height.
  8. Check (optional) that base > 0 and height > 0; else display error.
  9. Display the area with 2 decimal places.
  10. Stop.

5. Program Codes

Program 1A — Area using ½ × base × height 


"""
Program 1A: Calculate area of a triangle using ½ × base × height.
Course   : Python Programming (B.Sc. IT — Sem V)
"""

# --- Step 1: Read input ---
base = float(input("Enter the base of the triangle (in cm): "))
height = float(input("Enter the height of the triangle (in cm): "))

# --- Step 2: Compute area ---
area = 0.5 * base * height

# --- Step 3: Display result ---
print(f"Base   = {base} cm")
print(f"Height = {height} cm")
print(f"Area   = {area} cm²")

Sample Run 


Enter the base of the triangle (in cm): 10
Enter the height of the triangle (in cm): 6

Base   = 10.0 cm
Height = 6.0 cm
Area   = 30.0 cm²

Program 1B — Area using ½ × base × height 


"""
Program 1B: Validate inputs before computing area.
"""

base = float(input("Enter the base   : "))
height = float(input("Enter the height: "))

if base <= 0 or height <= 0:
    print("Base and height must be positive numbers.")
else:
    area = 0.5 * base * height
    print(f"Area of the triangle = {area:.2f} cm²")

Sample Run 


Enter the base   : 7
Enter the height: -3

Base and height must be positive numbers.
