Practical No. 05

Swap First and Last Elements of a List Using Python

1. Aim

To write Python programs to swap the first and last elements of a list using different techniques and to handle special cases such as an empty list or a single-element list.

2. Theory

What is a List?

A list is an ordered collection of elements in Python.

A list is written using square brackets [ ]. 


numbers = [10, 20, 30, 40, 50]

The elements are stored at different positions called indexes.

Python Uses Zero-Based Indexing

Element Index
10 0
20 1
30 2
40 3
50 4

The first element is accessed using: 


numbers[0]

The last element can be accessed using: 


numbers[-1]

Negative indexing counts from the end of the list.

3. First and Last Elements

Consider the following list: 


numbers = [10, 20, 30, 40, 50]

Then: 


numbers[0]

gives: 


10

and: 


numbers[-1]

gives: 


50

Therefore, to swap the first and last elements, we need to exchange: 


10 ↔ 50

The resulting list should be: 


[50, 20, 30, 40, 10]

4. Lists are Mutable

Python lists are mutable, which means their elements can be changed after the list is created.

For example: 


numbers = [10, 20, 30]

numbers[0] = 100

print(numbers)

Output: 


[100, 20, 30]

This property allows us to directly replace elements inside a list.

5. Algorithm

Using a Temporary Variable

  1. Start.
  2. Create the list.
  3. Check whether the list contains at least two elements.
  4. Store the first element in a temporary variable.
  5. Copy the last element into the first position.
  6. Copy the temporary value into the last position.
  7. Display the updated list.
  8. Stop.

6. Program Codes

Program A — Using a Temporary Variable

Swap the first and last elements using a temporary variable. 


# Program 5A
# Swap the first and last elements using a temporary variable

lst = [10, 20, 30, 40, 50]

print("Before:", lst)

if len(lst) >= 2:

    temp = lst[0]

    lst[0] = lst[-1]

    lst[-1] = temp

else:

    print("No swap needed.")

print("After:", lst)

Output 


Before: [10, 20, 30, 40, 50]

After: [50, 20, 30, 40, 10]

Explanation

Initially: 


First element = 10
Last element  = 50

We first store 10 in temp.

Then: 


lst[0] = lst[-1]

changes the first element to 50.

Finally: 


lst[-1] = temp

places the original 10 at the end.

7. Program B — Using a Function

A function makes the solution reusable. 


# Program 5D
# Swap the first and last elements using a function

def swap_first_last(lst):

    if len(lst) >= 2:

        lst[0], lst[-1] = lst[-1], lst[0]

    return lst


data = [10, 20, 30, 40, 50]

print("Before:", data)

result = swap_first_last(data)

print("After:", result)

Output 


Before: [10, 20, 30, 40, 50]

After: [50, 20, 30, 40, 10]

This version uses a reusable function and modifies the original list.

8. Handling Special Cases

A proper program should also handle lists that cannot actually be swapped.

Case 1: Empty List 


lst = []

There is no first or last element.

No swap is possible.

Case 2: Single-Element List 


lst = [10]

The first and last element are actually the same element.

There is nothing to swap.

Case 3: Two-Element List 


lst = [10, 20]

The result is: 


[20, 10]

9. Result

The Python programs to swap the first and last elements of a list were successfully implemented using:

  • Temporary variable
  • User-defined function

We also learned how to swap the first and last elements of a list using a temporary variable and a user-defined function. Special cases such as empty lists, single-element lists, and two-element lists were also considered.
