Practical No. 10

Implement the Tower of Hanoi Algorithm in Python

1. Aim

To implement the Tower of Hanoi puzzle using a recursive function in Python and verify that the minimum number of moves is 2ⁿ − 1.

2. Theory

The Tower of Hanoi consists of three pegs and n disks of different sizes. Initially, all disks are placed on the source peg in decreasing order of size.

Rules:

  1. Only one disk can be moved at a time.
  2. Only the top disk of a peg can be moved.
  3. A larger disk cannot be placed on a smaller disk.

The problem is solved using recursion. To move n disks:

  1. Move the top n−1 disks from the source to the auxiliary peg.
  2. Move the largest disk from the source to the target peg.
  3. Move the n−1 disks from the auxiliary peg to the target peg.

The minimum number of moves is:

2ⁿ − 1

For example:

  • 1 disk → 1 move
  • 2 disks → 3 moves
  • 3 disks → 7 moves
  • 4 disks → 15 moves

3. Algorithm

  1. Start.
  2. Read the number of disks n.
  3. If n ≤ 0, display an error message and stop.
  4. Define the recursive function hanoi(n, source, auxiliary, target).
  5. If n == 1, move the disk from source to target and return.
  6. Move n−1 disks from source to auxiliary.
  7. Move disk n from source to target.
  8. Move n−1 disks from auxiliary to target.
  9. Call the function with A as source, B as auxiliary, and C as target.
  10. Display the total number of moves and the expected minimum, 2ⁿ − 1.
  11. Stop.

4. Program

def hanoi(n, source, auxiliary, target, moves):
    if n == 1:
        moves.append((source, target))
        print(f"Move disk 1 from {source} to {target}")
        return

    # Move n-1 disks to auxiliary peg
    hanoi(n - 1, source, target, auxiliary, moves)

    # Move the largest disk to target peg
    moves.append((source, target))
    print(f"Move disk {n} from {source} to {target}")

    # Move n-1 disks to target peg
    hanoi(n - 1, auxiliary, source, target, moves)


n = int(input("Enter the number of disks: "))

if n <= 0:
    print("Please enter a positive number of disks.")
else:
    print(f"\nSequence of moves for {n} disk(s) from A to C:\n")

    moves = []
    hanoi(n, "A", "B", "C", moves)

    print(f"\nTotal moves made : {len(moves)}")
    print(f"Expected minimum : {2 ** n - 1}")

6. Conclusion

The Tower of Hanoi problem was successfully implemented using recursion. The program generates the correct sequence of moves and verifies that the minimum number of moves is 2ⁿ − 1.
