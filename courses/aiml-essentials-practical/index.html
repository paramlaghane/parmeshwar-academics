Semester V • Laboratory Course

Course Overview

This laboratory course complements the theory course by providing hands-on experience in Artificial Intelligence and Machine Learning. Students will implement logic, probability, Bayesian reasoning, decision trees, and neural networks through practical experiments using Python and suitable software tools.

Pre-requisites

  • Basic knowledge of Python Programming.
  • Basic understanding of Artificial Intelligence concepts.
  • Ability to write simple Python programs.
  • Familiarity with logical reasoning and mathematical concepts.

Course Objectives

  • Develop conceptual understanding of AI and Machine Learning fundamentals.
  • Build analytical skills for reasoning under uncertainty.
  • Understand optimization using evolutionary techniques.
  • Evaluate Machine Learning models.
  • Gain practical knowledge of Neural Networks, NLP and Generative AI.
  • Understand ethical and responsible AI practices.

Course Outcomes

  • CO1: Explain the fundamental principles and evolution of Artificial Intelligence.
  • CO2: Apply logical and probabilistic reasoning to Artificial Intelligence problems.
  • CO3: Analyze evolutionary algorithms for optimization tasks.
  • CO4: Distinguish different Machine Learning models and learning paradigms.
  • CO5: Describe Generative AI models and their applications.

Laboratory Experiments

Experiment 1 – Logic and Knowledge Representation

Practical Hours: 4 Hours

Objectives

  • Solve logical reasoning problems using Boolean Algebra.
  • Construct semantic networks to represent objects and their relationships.
  • Understand knowledge representation techniques used in AI systems.
  • Implement simple logic-based reasoning using Python.

Software Required: Python 3.x, VS Code / Jupyter Notebook

Experiment 2 – Probability Concepts in Artificial Intelligence

Practical Hours: 4 Hours

Objectives

  • Perform probability experiments using a six-sided die.
  • Calculate probabilities of simple and compound events.
  • Apply Bayes' Theorem to update probabilities using observed evidence.
  • Implement probability calculations using Python programs.

Software Required: Python 3.x, NumPy, Jupyter Notebook

Experiment 3 – Bayesian Networks

Practical Hours: 4 Hours

Objectives

  • Construct a simple Bayesian Network for a real-world problem.
  • Define Conditional Probability Tables (CPTs).
  • Perform probabilistic inference using observed evidence.
  • Analyze decision-making under uncertainty using Bayesian reasoning.

Software Required: Python 3.x, pgmpy / pomegranate, Jupyter Notebook

Experiment 4 – Machine Learning: Decision Trees

Practical Hours: 4 Hours

Objectives

  • Build a Decision Tree model using a sample dataset.
  • Visualize the decision tree structure.
  • Classify data based on selected attributes.
  • Evaluate model performance using prediction accuracy.

Software Required: Python 3.x, Scikit-learn, Pandas, Matplotlib, Jupyter Notebook

Experiment 5 – Neural Networks

Practical Hours: 4 Hours

Objectives

  • Design a simple Feedforward Neural Network.
  • Train the neural network using a sample dataset.
  • Observe learning behaviour and prediction accuracy.
  • Understand the role of activation functions and hidden layers.

Software Required: Python 3.x, TensorFlow/Keras, NumPy, Jupyter Notebook

  • Read the experiment before attending the laboratory session.
  • Write and execute programs independently.
  • Record observations, outputs, and conclusions in the laboratory journal.
  • Verify program results before submitting the practical.
  • Follow ethical coding practices and maintain academic integrity.
