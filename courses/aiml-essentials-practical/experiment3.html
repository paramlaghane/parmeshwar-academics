Bayesian Network — Construction and Inference

Bayesian Network — Construction and Inference

1. Aim

To construct a simple Bayesian Network using Python and perform probabilistic inference using Conditional Probability Tables (CPTs).

2. Objectives

After completing this practical, students will be able to:

  1. Understand the basic concept of a Bayesian Network.
  2. Construct a simple Bayesian Network.
  3. Define Conditional Probability Tables (CPTs).
  4. Calculate probabilities using the network.

3. Theory

3.1 What is a Bayesian Network?

A Bayesian Network is a graphical model used to represent uncertain events and their relationships.

It consists of:

  • Nodes → represent variables.
  • Arrows → represent relationships between variables.
  • CPTs → represent probabilities.

In simple words: 


Bayesian Network = Graph + Probability Tables

The graph is a Directed Acyclic Graph (DAG), which means the arrows have a direction and there is no cycle.

3.2 Example: Wet Grass Problem

We use a simple example to understand the concept.

Suppose:

  • It may be Cloudy.
  • Cloudy weather may affect the Sprinkler.
  • Cloudy weather may affect Rain.
  • Sprinkler and Rain may make the Grass Wet.

Network 


              Cloudy
              /    \
             ↓      ↓
        Sprinkler   Rain
             \      /
              \    /
               ↓  ↓
             WetGrass

This is the classic Wet Grass Bayesian Network used in the practical.

4. Conditional Probability Table (CPT)

A CPT tells us the probability of a variable when its parent is known.

Sprinkler given Cloudy

Cloudy P(Sprinkler = True) P(Sprinkler = False)
True 0.1 0.9
False 0.5 0.5

Rain given Cloudy

Cloudy P(Rain = True) P(Rain = False)
True 0.8 0.2
False 0.2 0.8

WetGrass given Sprinkler and Rain

Sprinkler Rain P(WetGrass = True) P(WetGrass = False)
True True 0.99 0.01
True False 0.90 0.10
False True 0.90 0.10
False False 0.00 1.00

These are the CPT values used in the practical.

6. Procedure

Step 1: Import Libraries 


from pgmpy.models import BayesianNetwork

from pgmpy.factors.discrete import TabularCPD

from pgmpy.inference import VariableElimination

Step 2: Create the Bayesian Network 


model = BayesianNetwork([

    ("Cloudy", "Sprinkler"),

    ("Cloudy", "Rain"),

    ("Sprinkler", "WetGrass"),

    ("Rain", "WetGrass")

])

This creates the following relationships: 


Cloudy → Sprinkler

Cloudy → Rain

Sprinkler → WetGrass

Rain → WetGrass

Step 3: Define CPTs

Cloudy 


cpd_cloudy = TabularCPD(

    variable="Cloudy",

    variable_card=2,

    values=[[0.5], [0.5]],

    state_names={
        "Cloudy": ["True", "False"]
    }

)

Sprinkler 


cpd_sprinkler = TabularCPD(

    variable="Sprinkler",

    variable_card=2,

    values=[

        [0.1, 0.5],

        [0.9, 0.5]

    ],

    evidence=["Cloudy"],

    evidence_card=[2],

    state_names={

        "Sprinkler": ["True", "False"],

        "Cloudy": ["True", "False"]

    }

)

Rain 


cpd_rain = TabularCPD(

    variable="Rain",

    variable_card=2,

    values=[

        [0.8, 0.2],

        [0.2, 0.8]

    ],

    evidence=["Cloudy"],

    evidence_card=[2],

    state_names={

        "Rain": ["True", "False"],

        "Cloudy": ["True", "False"]

    }

)

WetGrass 


cpd_wetgrass = TabularCPD(

    variable="WetGrass",

    variable_card=2,

    values=[

        [0.99, 0.90, 0.90, 0.00],

        [0.01, 0.10, 0.10, 1.00]

    ],

    evidence=["Sprinkler", "Rain"],

    evidence_card=[2, 2],

    state_names={

        "WetGrass": ["True", "False"],

        "Sprinkler": ["True", "False"],

        "Rain": ["True", "False"]

    }

)

Step 4: Add CPTs and Check the Model 


model.add_cpds(

    cpd_cloudy,

    cpd_sprinkler,

    cpd_rain,

    cpd_wetgrass

)

print("Model is valid:", model.check_model())

Expected Output 


Model is valid: True

The check_model() method verifies that the Bayesian Network and its CPTs are correctly defined.

7. Perform Inference

Inference means finding the probability of an event using the Bayesian Network.

Create the inference object: 


infer = VariableElimination(model)

7.1 Marginal Probability

Find the probability that the grass is wet. 


result = infer.query(

    variables=["WetGrass"]

)

print(result)

Result 


P(WetGrass = True) = 0.6471

Before knowing anything else, there is approximately a 64.71% probability that the grass is wet.

8. Inference with Evidence

Now suppose we know that it is raining.

Find: 


P(WetGrass = True | Rain = True)


result = infer.query(

    variables=["WetGrass"],

    evidence={"Rain": "True"}

)

print(result)

Result 


P(WetGrass = True | Rain = True) = 0.9162

When we know that it is raining, the probability of wet grass increases from: 


0.6471 → 0.9162

This shows how evidence changes probability.

9. Explaining Away

Now consider: 


P(Sprinkler = True | WetGrass = True)


print(

    infer.query(

        variables=["Sprinkler"],

        evidence={"WetGrass": "True"}

    )

)

Result 


P(Sprinkler = True | WetGrass = True) = 0.4301

Now suppose we also know that it rained: 


print(

    infer.query(

        variables=["Sprinkler"],

        evidence={

            "WetGrass": "True",

            "Rain": "True"

        }

    )

)

Result 


P(Sprinkler = True | WetGrass = True, Rain = True) = 0.1945

Simple Explanation

Initially: 


Wet grass → Sprinkler probability = 0.4301

After we learn that it rained: 


Sprinkler probability = 0.1945

Why?

Because rain provides another explanation for the wet grass.

This reduction in the probability of one explanation after learning another explanation is called explaining away.

10. Important Results

Query Probability
P(WetGrass = True) 0.6471
P(WetGrass = True | Rain = True) 0.9162
P(Sprinkler = True | WetGrass = True) 0.4301
P(Sprinkler = True | WetGrass = True, Rain = True) 0.1945

These are the key results obtained from the specified network and CPTs.

A simple Bayesian Network was successfully created using Python and pgmpy.

The network was used to:

  • Define variables and their relationships.
  • Define Conditional Probability Tables (CPTs).
  • Validate the model.
  • Calculate probabilities.
  • Perform inference using evidence.
  • Demonstrate explaining away.

12. Conclusion

In this practical, we learned that a Bayesian Network represents variables, relationships, and probabilities.

The main idea is: 


Build the Network → Define CPTs →
Give Evidence → Calculate Updated Probability

We also learned that observing new evidence can change our belief about other variables.

The explaining-away example showed that when rain is observed, the probability that the sprinkler caused the wet grass decreases.
