Theory A Decision Tree is a supervised machine learning algorithm used for both classification and regression. It recursively applies decision rules at different nodes to divide the training data into subsets containing similar target values or classes. A decision tree starts with the complete dataset at the root node and recursively divides the data into smaller subsets. The splitting process continues until the subsets become sufficiently pure or no further useful improvement in purity can be achieved. 2.1 Components of a Decision Tree A decision tree consists of the following components: • Root Node: The first and most important decision point in the tree. • Internal Node: Represents a decision or condition based on an attribute. • Branch: Represents the outcome of a decision. • Leaf Node: Represents the final predicted class or value. ________________________________________ 3. Splitting Criteria Decision trees use measures such as Entropy, Gini Index, and Information Gain to determine the best attribute for splitting the data. 3.1 Entropy Entropy measures the impurity or uncertainty present in a dataset. Entropy(D) = -Σ(i=1 to n) pᵢ log₂(pᵢ) where: D = dataset pᵢ = proportion of records belonging to class i For a binary classification problem, entropy ranges from 0 to 1. • Entropy = 0: The node is completely pure. • Higher entropy: The node contains greater class uncertainty. ________________________________________ 3.2 Gini Index The Gini Index is another measure of impurity. Gini(D) = 1 - Σ(i=1 to n) pᵢ² A Gini value of 0 indicates a completely pure node. ________________________________________ 3.3 Information Gain Information Gain measures the reduction in entropy after splitting the dataset. Gain(D,A) = Entropy(D) - Σ(v ∈ Values(A)) [ |Dᵥ| / |D| × Entropy(Dᵥ) ] where: • (D) = parent dataset • (A) = selected attribute • (D_v) = subset produced by a particular value of attribute (A) The attribute with the highest Information Gain is selected as the best split. Thus, the decision tree attempts to select a split that produces the purest possible child nodes. ________________________________________ 4. Common Decision Tree Algorithms Different decision tree algorithms use different splitting criteria: Algorithm Splitting Criterion ID3 Information Gain C4.5 Gain Ratio CART Gini Index C4.5 uses Gain Ratio to reduce the bias toward attributes having a large number of distinct values. ________________________________________ 5. Overfitting in Decision Trees A decision tree can become very deep and complex if it continues splitting the training data until the observations are almost perfectly separated. Such an unpruned tree may achieve very high training accuracy but perform poorly on unseen data. This is known as overfitting. Overfitting can be controlled using techniques such as: • max_depth • min_samples_leaf • Cost-complexity pruning using ccp_alpha The cost-complexity pruning objective can be represented as: C(T) = E(T) + λL(T) where: T = decision tree E(T) = error of the tree L(T) = complexity or number of leaves λ = parameter controlling the trade-off between error and tree complexity ________________________________________ 6. Algorithm 1. Load the dataset. 2. Separate the independent attributes (X) and target variable (y). 3. Encode categorical attributes into numerical form. 4. Calculate the entropy of the complete dataset. 5. For each attribute, calculate the weighted entropy of the resulting subsets. 6. Calculate the Information Gain for each attribute. 7. Select the attribute having the highest Information Gain as the root node. 8. Split the dataset according to the selected attribute. 9. Repeat the splitting process recursively for the resulting subsets. 10. Stop splitting when the node becomes pure, no useful gain is possible, or a specified stopping condition is reached. 11. Assign the majority class to the leaf node. 12. Use the resulting tree to predict new observations. 13. Evaluate the model using appropriate evaluation measures such as a confusion matrix and cross-validation. 14. Apply pruning or depth limitations to control overfitting. ________________________________________ 7.
