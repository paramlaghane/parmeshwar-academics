Bayes' Theorem: Fire Detection Using Smoke

Bayes' Theorem: Fire Detection Using Smoke

1. Aim

To apply Bayes' Theorem to determine the probability that a fire has occurred when smoke is detected. This practical demonstrates how Artificial Intelligence systems update their beliefs when new evidence becomes available.

2. Theory

Bayes' Theorem is a mathematical formula used to update the probability of a hypothesis when new evidence becomes available. It combines prior knowledge with observed evidence to calculate an updated probability called the posterior probability.

The formula for Bayes' Theorem is 


P(Fire | Smoke)
=
[P(Smoke | Fire) × P(Fire)]
----------------------------
       P(Smoke)

where

  • P(Fire) = Prior probability of fire
  • P(Smoke | Fire) = Probability of detecting smoke when there is a fire (Likelihood)
  • P(Smoke) = Probability of observing smoke (Evidence)
  • P(Fire | Smoke) = Posterior probability of fire after observing smoke

3. Problem Setup

Suppose a smart building is equipped with smoke sensors.

Assume the following probabilities:

  • Prior probability of fire 
    P(Fire) = 1% = 0.01
  • Probability of detecting smoke when there is a fire 
    P(Smoke | Fire) = 90% = 0.90
  • Probability of observing smoke 
    P(Smoke) = 10% = 0.10

4. Applying Bayes' Theorem

Substitute the given values into Bayes' Theorem. 


P(Fire | Smoke)

= (P(Smoke | Fire) × P(Fire))
  ---------------------------
          P(Smoke)

= (0.90 × 0.01)
  -------------
      0.10

= 0.009
  -----
  0.10

= 0.09

Therefore, 


P(Fire | Smoke) = 9%

This means that when smoke is detected, the probability that a fire is actually occurring increases from 1% to 9%.

This example demonstrates how Artificial Intelligence systems update their beliefs when new evidence becomes available.

5. Algorithm

  1. Assume the prior probability of fire.
  2. Assume the probability of observing smoke when there is a fire.
  3. Assume the probability of observing smoke.
  4. Apply Bayes' Theorem.
  5. Calculate the posterior probability of fire.
  6. Display the result.

6. Observation Table

Parameter Value
Prior Probability, P(Fire) 0.01
Likelihood, P(Smoke | Fire) 0.90
Evidence, P(Smoke) 0.10
Posterior Probability, P(Fire | Smoke) 0.09

7. Python Program 


# Bayes' Theorem for Fire Detection

# Prior probability
p_fire = 0.01

# Likelihood
p_smoke_given_fire = 0.90

# Evidence
p_smoke = 0.10

# Apply Bayes' Theorem
posterior = (p_smoke_given_fire * p_fire) / p_smoke

print("Prior Probability P(Fire) =", p_fire)
print("Likelihood P(Smoke|Fire) =", p_smoke_given_fire)
print("Evidence P(Smoke) =", p_smoke)
print("Posterior Probability P(Fire|Smoke) =", round(posterior, 2))

8. Program Explanation

  • The variable p_fire stores the prior probability that a fire has occurred.
  • The variable p_smoke_given_fire stores the likelihood of detecting smoke when a fire is present.
  • The variable p_smoke stores the probability of observing smoke.
  • The posterior probability is calculated by directly applying Bayes' Theorem.
  • The round() function displays the posterior probability rounded to two decimal places.
  • The print() function displays all probabilities in a clear and readable format.

9. Sample Output 


Prior Probability P(Fire) = 0.01
Likelihood P(Smoke|Fire) = 0.9
Evidence P(Smoke) = 0.1
Posterior Probability P(Fire|Smoke) = 0.09

10. Key Points to Remember

  • Bayes' Theorem updates an existing belief using new evidence.
  • Prior Probability represents the initial belief before observing evidence.
  • Likelihood represents the probability of observing the evidence when the hypothesis is true.
  • Evidence is the overall probability of observing the evidence.
  • Posterior Probability is the updated probability after considering the evidence.
  • Bayes' Theorem is widely used in Artificial Intelligence, Machine Learning, medical diagnosis, spam filtering, robotics, and decision-making systems.

11. Result

Using Bayes' Theorem, the probability of fire increased from 1% (prior probability) to 9% (posterior probability) after smoke was detected. This demonstrates how Bayes' Theorem updates beliefs based on new evidence and forms the foundation of probabilistic reasoning in Artificial Intelligence.
