Practical 7 — Generative Intelligence: Creative Tasks

Generative Intelligence: Creative Tasks

Course: AIML Essentials
Course Code: MDI41MMP301
Duration: 3 Hours

1. Aim

To explore generative concepts by creating images and patterns, and to experiment with shapes, patterns, and digital creativity using rule-based generation and a deep generative model.

2. Theory

2.1 Generative Models vs. Discriminative Models

A discriminative model learns to predict a label or class from input data.

A generative model learns the underlying data distribution itself and can use that learned distribution to generate new data.

Generative modeling deals with learning distributions such as:

P(X)

where X represents the data.

For images, each data point may contain thousands or millions of dimensions because an image consists of many pixels. A generative model therefore needs to learn the relationships and dependencies between these pixels.

2.2 Two Routes to Machine Creativity

There are two important approaches to generating creative outputs.

A. Rule-Based / Procedural Generation

In rule-based generation, the programmer defines a set of rules or parameters, and the computer generates new patterns or designs according to those rules.

Typical rules may involve:

  • Rotation
  • Scaling
  • Branching
  • Repetition
  • Position
  • Color
  • Randomness

Important techniques include:

Shape Grammars: Generative methods that create design alternatives using geometric rules and logic.

L-Systems: A rule-based method in which a starting string, called an axiom, is repeatedly rewritten according to specified rules. The resulting string can then be interpreted as drawing instructions.

Once a pattern or rule has been established, many variations can be generated by changing parameters or random seeds.

B. Learned Generative Models

Deep generative models learn patterns and distributions from data.

Three important families are:

Model Mechanism Important Point
VAE Encoder compresses input into a lower-dimensional latent space and decoder reconstructs the input. New data can be generated by sampling points from the latent space and decoding them.
GAN A generator and discriminator compete with each other. Can generate highly realistic data, including images.
Diffusion Model Learns to gradually denoise data. Particularly powerful for text-to-image generation.

Variational Autoencoder (VAE)

A VAE consists mainly of:

  1. Encoder — converts an input image into latent variables.
  2. Latent Space — compact representation of the input.
  3. Decoder — reconstructs or generates an image from a latent point.

The VAE is trained using an objective based on the Evidence Lower Bound (ELBO), which contains:

  • Reconstruction term
  • KL-divergence term

The reconstruction term encourages the decoder to reconstruct the original image, while the KL term encourages the latent space to follow a suitable probability distribution.

Generative Adversarial Network (GAN)

A GAN contains:

  • Generator — creates synthetic data.
  • Discriminator — attempts to distinguish real data from generated data.

The two networks compete during training.

GANs have been used for generating realistic faces, visual art, music, and text.

Important challenges include:

  • Image quality
  • Diversity of generated samples
  • Training stability

Diffusion Models

Diffusion models generate data by learning a denoising process.

They are particularly effective for text-to-image generation, where a textual description can be used to generate an image containing combinations of objects, shapes, textures, and other concepts.

2.3 Creativity and Human–AI Collaboration

Generative models can produce novel outputs, but their creativity is generally based on patterns learned from existing data.

For example, GANs commonly demonstrate exploratory creativity, where new outputs are produced within a learned distribution.

In practical design applications, generative AI is therefore best viewed as a tool for human–AI collaboration, rather than simply replacing human creativity.

3. Algorithm / Procedure

  1. Define the creative goal, such as generating a pattern, shape, or image.
  2. For rule-based generation, select a shape, rule, and random seed.
  3. Generate and render the pattern.
  4. Change one rule at a time and generate the pattern again.
  5. For an L-system, select:
    • Axiom
    • Rewriting rule
    • Turning angle
    • Depth
  6. Expand the string according to the rewriting rule.
  7. Interpret the resulting string as turtle-graphics movements and plot the pattern.
  8. For deep generative modeling, load a dataset of images.
  9. Train an autoencoder/VAE to represent images in a latent space.
  10. Sample a point from the latent space and decode it to generate a new image.
  11. Interpolate between two latent points to observe a smooth transition between generated images.
  12. Evaluate the generated outputs for:
    • Novelty
    • Variety
    • Recognisability
  13. Record the rules, parameters, seeds, or prompts used to generate each result.

4. Implementation

Activity A — Rule-Based Pattern

Objective

To investigate how changing rules and random seeds produces different patterns from the same basic generation procedure.

Python Code
import numpy as np
import matplotlib.pyplot as plt


def draw_pattern(ax, n=40, angle=7.5, shrink=0.94, seed=0):

    rng = np.random.default_rng(seed)

    theta = np.linspace(0, 2 * np.pi, 5)

    # Base shape
    base = np.c_[np.cos(theta), np.sin(theta)]

    size = 1.0
    rot = 0.0

    for i in range(n):

        # Rotation rule
        rot += np.deg2rad(angle)

        c, s = np.cos(rot), np.sin(rot)

        R = np.array([
            [c, -s],
            [s,  c]
        ])

        # Scaling + rotation
        pts = (base * size) @ R.T

        ax.plot(
            pts[:, 0],
            pts[:, 1],
            color=plt.cm.twilight(i / n),
            lw=1.2,
            alpha=0.9
        )

        # Scaling + controlled randomness
        size *= shrink * rng.uniform(0.98, 1.02)

    ax.set_aspect("equal")
    ax.axis("off")


fig, axes = plt.subplots(1, 3, figsize=(12, 4))

for ax, s in zip(axes, [0, 1, 2]):
    draw_pattern(ax, seed=s)
    ax.set_title(f"seed = {s}")

plt.suptitle("One Rule Set, Three Different Artworks")
plt.tight_layout()
plt.show()

Explanation

The function uses:

  • angle — controls the amount of rotation.
  • shrink — controls how quickly the pattern decreases in size.
  • seed — controls reproducible randomness.
  • n — controls the number of repeated shapes.

Changing the seed while keeping the rules unchanged produces related but different patterns.

Activity B — L-System

Objective

To generate a recursively growing pattern using a string-rewriting system.

Step 1 — Define the Expansion Function

Python Code
import numpy as np
import matplotlib.pyplot as plt


def expand(axiom, rules, n):

    s = axiom

    for _ in range(n):
        s = "".join(rules.get(ch, ch) for ch in s)

    return s

Step 2 — Define the Renderer

Python Code
def render(s, angle=25, step=1.0):

    x, y, d = 0.0, 0.0, 90.0

    xs, ys, stack = [x], [y], []

    for ch in s:

        if ch == "F":
            # F = draw forward
            x += step * np.cos(np.deg2rad(d))
            y += step * np.sin(np.deg2rad(d))

            xs.append(x)
            ys.append(y)

        elif ch == "+":
            # + = turn left
            d += angle

        elif ch == "-":
            # - = turn right
            d -= angle

        elif ch == "[":
            # [ = remember position
            stack.append((x, y, d))

        elif ch == "]":
            # ] = return to previous position
            x, y, d = stack.pop()

            xs.append(np.nan)
            ys.append(np.nan)

    return xs, ys

Step 3 — Generate the L-System

Python Code
for depth in [2, 4]:

    s = expand(
        "F",
        {"F": "F[+F]F[-F]F"},
        depth
    )

    xs, ys = render(
        s,
        angle=25,
        step=1.0
    )

    plt.figure(figsize=(6, 6))

    plt.plot(
        xs,
        ys,
        lw=0.7,
        color="forestgreen"
    )

    plt.axis("equal")
    plt.axis("off")
    plt.title(f"L-system, depth {depth}")

    plt.show()

Explanation of Symbols

Symbol Meaning
F Move forward and draw
+ Turn left
- Turn right
[ Save the current position and direction
] Return to the saved position and direction

The pattern grows through repeated rewriting of the original string.

Activity C — Variational Autoencoder (VAE)

Objective

To train a VAE on MNIST handwritten digits and generate new digit-like images by sampling points from the learned latent space.

Step 1 — Load and Prepare MNIST Data

Python Code
import numpy as np
import matplotlib.pyplot as plt

import tensorflow as tf
from tensorflow.keras import layers, Model


# MNIST images scaled to [0, 1]
(x_train, _), (x_test, _) = tf.keras.datasets.mnist.load_data()

x_train = (x_train.astype("float32") / 255.0)[..., None]
x_test  = (x_test.astype("float32") / 255.0)[..., None]

Step 2 — Define the Latent Space

Python Code
latent_dim = 2

A two-dimensional latent space is deliberately selected so that it can be visualised.

Step 3 — Build the Encoder

Python Code
enc_in = layers.Input(shape=(28, 28, 1))

h = layers.Dense(
    128,
    activation="relu"
)(layers.Flatten()(enc_in))

z_mean = layers.Dense(latent_dim)(h)

z_log_var = layers.Dense(latent_dim)(h)

The encoder converts each image into:

  • Latent mean
  • Latent log-variance

Step 4 — Sampling Using the Reparameterisation Trick

Python Code
def sampling(args):

    z_mean, z_log_var = args

    eps = tf.random.normal(
        shape=tf.shape(z_mean)
    )

    return (
        z_mean
        + tf.exp(0.5 * z_log_var) * eps
    )


z = layers.Lambda(sampling)(
    [z_mean, z_log_var]
)

encoder = Model(
    enc_in,
    [z_mean, z_log_var, z],
    name="encoder"
)

Step 5 — Build the Decoder

Python Code
dec_in = layers.Input(
    shape=(latent_dim,)
)

h = layers.Dense(
    128,
    activation="relu"
)(dec_in)

dec_out = layers.Reshape(
    (28, 28, 1)
)(
    layers.Dense(
        28 * 28,
        activation="sigmoid"
    )(h)
)

decoder = Model(
    dec_in,
    dec_out,
    name="decoder"
)

The decoder takes a point from the latent space and generates an image.

Step 6 — Define the VAE Loss

The VAE loss contains two components:

L = L_reconstruction + L_KL
Python Code
out = decoder(
    encoder(enc_in)[2]
)

vae = Model(
    enc_in,
    out,
    name="vae"
)

recon = tf.reduce_mean(
    tf.reduce_sum(
        tf.keras.losses.binary_crossentropy(
            enc_in,
            out
        ),
        axis=(1, 2)
    )
)

kl = -0.5 * tf.reduce_mean(
    tf.reduce_sum(
        1
        + z_log_var
        - tf.square(z_mean)
        - tf.exp(z_log_var),
        axis=1
    )
)

vae.add_loss(recon + kl)

vae.compile(
    optimizer="adam"
)

Step 7 — Train the VAE

Python Code
vae.fit(
    x_train,
    epochs=10,
    batch_size=128,
    verbose=2
)

Step 8 — Generate New Digits

Python Code
n = 15
span = 2.0

grid = np.linspace(
    -span,
    span,
    n
)

canvas = np.zeros(
    (28 * n, 28 * n)
)

for i, yi in enumerate(grid[::-1]):

    for j, xi in enumerate(grid):

        img = decoder.predict(
            np.array([[xi, yi]]),
            verbose=0
        )[0, :, :, 0]

        canvas[
            i*28:(i+1)*28,
            j*28:(j+1)*28
        ] = img


plt.figure(figsize=(10, 10))

plt.imshow(
    canvas,
    cmap="gray"
)

plt.title(
    "New Digits Decoded from a Grid of Latent Points"
)

plt.axis("off")
plt.show()

The decoder generates images from different points in the latent space.

Step 9 — Latent-Space Interpolation

Python Code
a = encoder.predict(
    x_test[0:1],
    verbose=0
)[0]

b = encoder.predict(
    x_test[1:2],
    verbose=0
)[0]

steps = 10

fig, axes = plt.subplots(
    1,
    steps,
    figsize=(steps, 1.4)
)

for k, t in enumerate(
    np.linspace(0, 1, steps)
):

    zt = (1 - t) * a + t * b

    axes[k].imshow(
        decoder.predict(
            zt,
            verbose=0
        )[0, :, :, 0],
        cmap="gray"
    )

    axes[k].axis("off")

plt.suptitle(
    "Latent-Space Interpolation: "
    "One Digit Morphing into Another"
)

plt.show()

Interpolation demonstrates how the decoder can produce intermediate outputs between two latent representations.

6. Conclusion

  1. Generative models learn the underlying data distribution rather than simply predicting labels. This enables them to generate new data.
  2. Rule-based generation demonstrates that creative patterns can be produced by defining rules and parameters. Activities A and B use rotation, scaling, branching, rewriting, and randomness to generate different artworks.
  3. L-systems generate patterns through repeated string rewriting and interpretation of the resulting symbols as drawing instructions.
  4. A VAE uses an encoder–decoder architecture to learn a latent representation of images. New images can be generated by sampling points from the latent space and decoding them.
  5. VAE training balances:
    • Reconstruction loss
    • KL-divergence loss
  6. GANs use a generator and discriminator that compete during training. Important challenges include image quality, diversity, and training stability.
  7. Diffusion models generate data through a denoising process and are particularly effective for text-to-image generation.
  8. Generative AI can produce novel outputs, but it is useful to distinguish exploratory creativity from transformational creativity.
  9. In practical applications, generative AI is best considered as a tool for human–AI collaboration.
  10. Always record the rules, parameters, random seed, or prompts used to generate an output. This makes the experiment reproducible, comparable, and explainable.
