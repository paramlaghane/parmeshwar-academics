3. Theory

3.1 What is Data Preprocessing?

Data preprocessing is the process of cleaning and transforming raw data into a suitable form for Machine Learning.

Real-world datasets may contain:

  • Missing values
  • Categorical/text data
  • Different numerical scales
  • Unnecessary columns
  • Inconsistent data

Therefore, preprocessing is an important step before training a Machine Learning model.

3.2 Handling Missing Values

A missing value is generally represented as NaN in Pandas.

There are two common ways to handle missing values:

Method Description Suitable When
Deletion Remove rows or columns containing missing values. When very little useful information is present.
Imputation Replace missing values with mean, median or mode. When only a few values are missing.

Common Methods

For numerical data:

  • Mean
  • Median

For categorical data:

  • Mode

The median is often preferred for numerical data when outliers are present, while the mode is commonly used for categorical data.

3.3 Normalization

Normalization transforms numerical values to a fixed range, usually 0 to 1.

Formula: 


X_norm = (X - X_min) / (X_max - X_min)

After normalization:

  • Minimum value becomes 0.
  • Maximum value becomes 1.
  • All other values lie between 0 and 1.

Normalization is sensitive to outliers.

3.4 Standardization

Standardization transforms the data so that:

  • Mean = 0
  • Standard deviation = 1

Formula: 


Z = (X - μ) / σ

where:

  • X = original value
  • μ = mean
  • σ = standard deviation

Standardized values are not restricted to 0 and 1. They may be positive or negative.

3.5 Normalization vs Standardization

Aspect Normalization Standardization
Main purpose Scale values to a fixed range. Centre and scale data.
Common range 0 to 1 Unbounded
Mean Not necessarily 0 0
Standard deviation Not necessarily 1 1
Scikit-learn class MinMaxScaler StandardScaler
Effect of outliers More sensitive Generally less sensitive

3.6 Training and Testing Data

Before training a Machine Learning model, the dataset is generally divided into two parts:

  • Training Data: used to train the model.
  • Testing Data: used to evaluate the trained model.

In this practical, we use:

  • 80% training data
  • 20% testing data

For classification problems, stratify=y can be used to maintain approximately the same class proportion in both sets.

8. Handle Missing Values

8.1 Handle Age Using Median

The Age column contains missing numerical values. We replace these missing values with the median age. 


age_median = df["Age"].median()

df["Age"] = df["Age"].fillna(age_median)

print("Missing Age values after imputation:")

print(df["Age"].isnull().sum())

8.2 Handle Embarked Using Mode

The Embarked column contains categorical values. Missing values are replaced using the mode. 


embarked_mode = df["Embarked"].mode()[0]

df["Embarked"] = df["Embarked"].fillna(embarked_mode)

print("Missing Embarked values after imputation:")

print(df["Embarked"].isnull().sum())

8.3 Handle Cabin Column

The Cabin column contains a large number of missing values. For this practical, the column is removed because it contains too much missing information. 


df = df.drop(columns=["Cabin"])

print("Cabin column removed.")

8.4 Verify Missing Values 


print("Missing Values After Preprocessing:")

print(df.isnull().sum())

The selected missing values have now been handled.

  • stratify=y maintains the class distribution in the training and testing sets.

11. Normalization

Normalization scales numerical features to a specified range, usually between 0 and 1.

Scikit-learn provides the MinMaxScaler class for normalization.

11.1 Apply Min-Max Normalization 


from sklearn.preprocessing import MinMaxScaler

normalizer = MinMaxScaler()

X_train_normalized = normalizer.fit_transform(X_train)

X_test_normalized = normalizer.transform(X_test)

print("Normalized Training Data:")

print(X_train_normalized[:5])

Important Point

The scaler is fitted only on the training data. 


normalizer.fit_transform(X_train)

The same fitted scaler is then used to transform the testing data. 


normalizer.transform(X_test)

This prevents information from the testing data from influencing the preprocessing process.

12. Standardization

Standardization transforms numerical features so that they have approximately:

  • Mean = 0
  • Standard deviation = 1

Scikit-learn provides the StandardScaler class.

15. Complete Python Program

The following program combines the major steps performed in this practical. 


import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

from sklearn.model_selection import train_test_split

from sklearn.preprocessing import MinMaxScaler
from sklearn.preprocessing import StandardScaler


# --------------------------------------------------
# Step 1: Load Dataset
# --------------------------------------------------

url = "https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv"

df = pd.read_csv(url)

print("Dataset loaded successfully.")

print("\nDataset Shape:")
print(df.shape)


# --------------------------------------------------
# Step 2: Explore Dataset
# --------------------------------------------------

print("\nFirst Five Records:")
print(df.head())

print("\nDataset Information:")
df.info()

print("\nStatistical Summary:")
print(df.describe())


# --------------------------------------------------
# Step 3: Check Missing Values
# --------------------------------------------------

print("\nMissing Values:")
print(df.isnull().sum())


# --------------------------------------------------
# Step 4: Handle Missing Values
# --------------------------------------------------

df["Age"] = df["Age"].fillna(

    df["Age"].median()

)

df["Embarked"] = df["Embarked"].fillna(

    df["Embarked"].mode()[0]

)

df = df.drop(columns=["Cabin"])


print("\nMissing Values After Preprocessing:")
print(df.isnull().sum())


# --------------------------------------------------
# Step 5: Select Features and Target
# --------------------------------------------------

features = [

    "Age",

    "Fare",

    "SibSp",

    "Parch"

]

X = df[features]

y = df["Survived"]


# --------------------------------------------------
# Step 6: Train-Test Split
# --------------------------------------------------

X_train, X_test, y_train, y_test = train_test_split(

    X,

    y,

    test_size=0.20,

    random_state=42,

    stratify=y

)

print("\nTraining Data Shape:")
print(X_train.shape)

print("\nTesting Data Shape:")
print(X_test.shape)


# --------------------------------------------------
# Step 7: Normalization
# --------------------------------------------------

normalizer = MinMaxScaler()

X_train_normalized = normalizer.fit_transform(X_train)

X_test_normalized = normalizer.transform(X_test)


# --------------------------------------------------
# Step 8: Standardization
# --------------------------------------------------

standardizer = StandardScaler()

X_train_standardized = standardizer.fit_transform(X_train)

X_test_standardized = standardizer.transform(X_test)


# --------------------------------------------------
# Step 9: Display Results
# --------------------------------------------------

print("\nOriginal Training Data:")
print(X_train.head())

print("\nNormalized Training Data:")
print(X_train_normalized[:5])

print("\nStandardized Training Data:")
print(X_train_standardized[:5])


print("\nData preprocessing completed successfully.")
