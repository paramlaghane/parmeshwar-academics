K-Means Clustering: Unsupervised Grouping of Data Points for Customer/Product Segmentation and Selecting the Optimal Number of Clusters

Practical No. 9

Title: K-Means Clustering: Unsupervised Grouping of Data Points for Customer/Product Segmentation and Selecting the Optimal Number of Clusters

Unit: III

Aim

To apply the K-Means clustering algorithm in Python to segment retail customers based on their Annual Income and Spending Score, and to determine the optimal number of clusters using the Elbow Method and the Silhouette Score.

Concept / Theory

Clustering is an unsupervised learning technique: unlike regression and classification, there is no target variable and no labelled training data. The algorithm discovers natural groupings (called clusters or segments) in the data on its own, such that points within a cluster are more similar to each other than to points in other clusters.

K-Means is a partitioning algorithm that divides the data into a pre-specified number of clusters, K. Each cluster is represented by its centroid — the mean position of all points assigned to it. Similarity is measured by Euclidean distance:

d(x, c) = √[Σj (xj − cj)²]

where x is a data point, c is a centroid, and m is the number of features.

Objective Function

K-Means minimises the Within-Cluster Sum of Squares, also called inertia:

WCSS = Σk=1K Σx∈Ck ‖x − μk‖²

where μk is the centroid of cluster k. Lower inertia means tighter, more compact clusters.

Choosing the Optimal K

1. Elbow Method — Plot inertia against K. Inertia always falls as K increases, but the rate of improvement drops sharply at the true number of clusters, producing a visible bend (elbow) in the curve. The K at that bend is chosen.

2. Silhouette Score — Measures how well each point fits its own cluster compared with the nearest other cluster:

s = (b − a) / max(a, b)

where a is the mean intra-cluster distance and b is the mean distance to the nearest neighbouring cluster. The score ranges from −1 to +1, and the K with the highest average silhouette score is preferred.

Important Preprocessing Step — Feature Scaling

K-Means relies on distance, so a variable measured on a larger scale (e.g., Annual Income in thousands) would dominate one on a smaller scale. Features are therefore standardised to zero mean and unit variance using StandardScaler before clustering.

Limitations

K must be specified in advance, results depend on the initial centroid placement (mitigated by n_init, which restarts the algorithm several times), the algorithm favours roughly spherical clusters of similar size, and it is sensitive to outliers.

Business Application

The resulting segments support targeted marketing — for example, identifying high-income/high-spending customers as a premium target group, or high-income/low-spending customers as a group to be encouraged to spend more.

Algorithm / Procedure

  1. Import the required libraries (Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn).
  2. Load the customer dataset into a DataFrame and inspect its structure.
  3. Select the clustering features (Annual Income, Spending Score).
  4. Standardise the features using StandardScaler.
  5. Plot the raw data to observe its spread before clustering.
  6. Run K-Means for a range of K values (1–10) and record the inertia for each.
  7. Plot the Elbow curve (inertia vs K) and identify the bend.
  8. Compute the Silhouette Score for each K (2–10) and plot it.
  9. Fit the final K-Means model with the chosen K and assign a cluster label to each customer.
  10. Plot the clusters with their centroids, and summarise each segment by its mean income and spending to interpret the segments.

Program / Implementation

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score


# Step 2: Create the retail customer dataset (18 customers)

data = {
    'CustomerID': list(range(1, 19)),

    'Annual_Income_k': [
        20, 25, 22, 28, 24, 26,      # low income group
        80, 85, 78, 82, 88, 84,      # high income, low spending
        85, 90, 88, 92, 86, 89       # high income, high spending
    ],

    'Spending_Score': [
        25, 30, 20, 32, 22, 28,
        20, 25, 18, 22, 28, 15,
        82, 88, 85, 90, 80, 84
    ]
}

df = pd.DataFrame(data)

print(df.head())
print(df.shape)             # (18, 3)
print(df.describe())


# Step 3: Select clustering features

X = df[['Annual_Income_k', 'Spending_Score']]


# Step 5: Visualize the raw data before clustering

sns.scatterplot(
    x='Annual_Income_k',
    y='Spending_Score',
    data=df
)

plt.title('Customers: Income vs Spending (Before Clustering)')
plt.xlabel('Annual Income (k$)')
plt.ylabel('Spending Score')

plt.show()


# Step 4: Standardise the features

scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)


# Step 6-7: Elbow method

inertia = []
K_range = range(1, 11)

for k in K_range:

    km = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    km.fit(X_scaled)
    inertia.append(km.inertia_)


plt.plot(K_range, inertia, marker='o')

plt.title('Elbow Method')
plt.xlabel('Number of Clusters (K)')
plt.ylabel('Inertia (WCSS)')

plt.show()


# Step 8: Silhouette scores

for k in range(2, 11):

    km = KMeans(
        n_clusters=k,
        random_state=42,
        n_init=10
    )

    labels = km.fit_predict(X_scaled)

    print(
        f"K = {k}, Silhouette Score = "
        f"{round(silhouette_score(X_scaled, labels), 3)}"
    )


# Step 9: Fit final model with K = 3

kmeans = KMeans(
    n_clusters=3,
    random_state=42,
    n_init=10
)

df['Cluster'] = kmeans.fit_predict(X_scaled)

print(df)


# Step 10a: Plot clusters with centroids

centroids = scaler.inverse_transform(
    kmeans.cluster_centers_
)

sns.scatterplot(
    x='Annual_Income_k',
    y='Spending_Score',
    hue='Cluster',
    palette='Set1',
    data=df,
    s=100
)

plt.scatter(
    centroids[:, 0],
    centroids[:, 1],
    c='black',
    marker='X',
    s=250,
    label='Centroids'
)

plt.title('Customer Segments (K = 3)')
plt.xlabel('Annual Income (k$)')
plt.ylabel('Spending Score')
plt.legend()

plt.show()


# Step 10b: Summarise each segment

print(
    df.groupby('Cluster')[
        ['Annual_Income_k', 'Spending_Score']
    ].mean().round(2)
)

print(df.groupby('Cluster').size())

How to Read the Outputs

  • Describe: Shows the spread of the two features — note that Annual Income ranges from 20 to 92 k$ while Spending Score ranges from 15 to 90, which is why standardisation is essential before clustering.
  • Elbow curve: Inertia falls steeply up to about K = 3 and then flattens, so the bend is expected at K = 3 — matching the three groups designed into this dataset. Read the bend from your own plot.
  • Silhouette scores: The highest average score is expected at K = 3, confirming the elbow. Compare the printed values; a score closer to +1 indicates dense, well-separated clusters, while scores near 0 indicate overlapping clusters.
  • Segment summary: The cluster means let you name each segment in business terms — one cluster sits at low income / low spending, one at high income / low spending, and one at high income / high spending.
  • Cluster numbering is arbitrary — the same segmentation may come out as Cluster 0, 1, 2 in a different order on a re-run; only the grouping matters, not the label numbers.

Graphs Displayed

  1. Scatter plot before clustering — the raw points, which already hint at three separate groups but with no labels attached.
  2. Elbow curve — inertia against K, with the characteristic bend at the chosen K.
  3. Silhouette score plot/printout — the average silhouette for each K, peaking at the recommended number of clusters.
  4. Clustered scatter plot — the same customers coloured by cluster, with a black X marking each centroid; the three colour groups appear clearly separated.

Result

K-Means clustering was successfully applied to segment 18 retail customers using Annual Income and Spending Score as features. The Elbow Method and Silhouette Score both indicated K = 3 as the optimal number of clusters, and the final model assigned every customer to one of three segments. The plotted clusters, together with the black centroids, showed three well-separated groups, and the segment summary revealed one low-income/low-spending group, one high-income/low-spending group, and one high-income/high-spending group.

Conclusion

K-Means is an unsupervised partitioning algorithm that groups data points into K clusters by minimising the within-cluster sum of squares, assigning each point to the nearest centroid by Euclidean distance. In this practical, it was used to create customer segments from income and spending data — the same approach the syllabus describes for creating product segments — and the practical demonstrated the two standard methods for selecting K: the Elbow Method, which looks for the bend in the inertia curve, and the Silhouette Score, which measures how well-separated the clusters are. Both pointed to three clusters, and the resulting segments are directly actionable for marketing decisions, such as targeting the high-income/high-spending group with premium offers. The practical also highlighted two practical requirements of the method: features must be standardised before clustering so that no single variable dominates the distance calculation, and the value of K must be chosen in advance, since the algorithm cannot discover the number of clusters on its own.
