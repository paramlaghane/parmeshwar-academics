Machine Learning Practical

Laboratory Course

Course Overview

This laboratory course provides practical experience in implementing core Machine Learning algorithms using Python and popular machine learning libraries. Students will perform experiments on regression, classification, clustering, Bayesian learning, neural networks, and instance-based learning while analyzing real-world datasets. The course emphasizes model development, evaluation, and interpretation through hands-on programming exercises.

Pre-requisites

  • Basic knowledge of Data Mining and Data Warehousing.
  • Basic Python programming skills.
  • Fundamental understanding of statistics.
  • Interest in data analysis and predictive modeling.

Course Objectives

  • Introduce the practical implementation of Machine Learning algorithms.
  • Develop skills in regression, classification, and clustering techniques.
  • Learn to evaluate machine learning models using standard performance metrics.
  • Gain hands-on experience with Python and Machine Learning libraries.

Course Outcomes

  • CO1: Become familiar with dimensionality reduction and machine learning techniques.
  • CO2: Select suitable machine learning algorithms for different problem domains.
  • CO3: Design, implement, evaluate, and interpret regression, classification, and clustering models.
  • CO4: Understand and implement practical data clustering techniques.

Laboratory Experiments

Experiment 1 – FIND-S Algorithm

Practical Hours: 2 Hours

Objectives

  • Understand the concept of hypothesis learning.
  • Implement the FIND-S algorithm using training data stored in a CSV file.
  • Determine the most specific hypothesis consistent with the training examples.
  • Analyze the learning process using sample datasets.

Software Required: Python 3.x, Jupyter Notebook / VS Code, Pandas
