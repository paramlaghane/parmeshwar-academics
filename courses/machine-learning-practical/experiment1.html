Installation of Python and Machine Learning Libraries and Basic Machine Learning Workflow

1. Aim

To install and configure Python and the required Machine Learning libraries, and to demonstrate the basic Machine Learning workflow using the Iris dataset.

2. Objectives

After completing this practical, students will be able to:

  1. Install Python on a computer.
  2. Install the basic Machine Learning libraries:
    • NumPy
    • Pandas
    • Matplotlib
    • Scikit-learn
  3. Verify that the libraries are installed correctly.
  4. Load and explore the Iris dataset.
  5. Perform basic data visualization.
  6. Divide the dataset into training and testing sets.

3. Theory

3.1 What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence in which computers learn patterns from data and use these patterns to make predictions or decisions.

Instead of writing rules for every possible situation, we provide data to the machine learning algorithm. The algorithm learns from the data and uses the learned patterns to make predictions on new data.

Example

Suppose we have information about flowers such as:

  • Sepal length
  • Sepal width
  • Petal length
  • Petal width

Using these features, a Machine Learning model can learn to identify the species of a flower.

3.2 Types of Machine Learning

The major types of Machine Learning are:

Type Description Examples
Supervised Learning The model learns from labelled data. Classification, Regression
Unsupervised Learning The model finds patterns in unlabelled data. Clustering, Dimensionality Reduction
Reinforcement Learning The model learns through rewards and penalties. Robotics, Game Playing

In this practical, we use Supervised Learning, because the Iris dataset contains known class labels.

3.3 Python Libraries Used

Matplotlib Data visualization
Scikit-learn Machine Learning algorithms and evaluation

4. Basic Machine Learning Workflow

A typical Machine Learning workflow consists of the following steps:

  1. Define the problem
  2. Collect the data
  3. Explore and clean the data
  4. Visualize the data
  5. Prepare the data
  6. Select and train a Machine Learning model
  7. Evaluate the model
  8. Make predictions

In this practical, all these steps are demonstrated using the Iris dataset.

5. Dataset Used — Iris Dataset

The Iris dataset is a commonly used dataset for learning Machine Learning.

It contains:

  • 150 samples
  • 4 features
  • 3 classes

Features

  1. Sepal Length
  2. Sepal Width
  3. Petal Length
  4. Petal Width

Classes

  1. Setosa
  2. Versicolor
  3. Virginica

Each class contains 50 samples.

The Iris dataset is already available in Scikit-learn, so no separate download is required.

9. Basic Machine Learning Workflow Using Iris Dataset

Step 1: Import Required Libraries 


import numpy as np

import pandas as pd

import matplotlib.pyplot as plt

from sklearn.datasets import load_iris

from sklearn.model_selection import train_test_split

from sklearn.preprocessing import StandardScaler

from sklearn.neighbors import KNeighborsClassifier

from sklearn.metrics import accuracy_score

from sklearn.metrics import confusion_matrix

from sklearn.metrics import classification_report

Step 2: Load the Iris Dataset 


iris = load_iris()

X = iris.data

y = iris.target

print("Feature names:")

print(iris.feature_names)

print("\nTarget names:")

print(iris.target_names)

print("\nNumber of samples:", X.shape[0])

print("Number of features:", X.shape[1])

Expected Result

The output should show:

  • 150 samples
  • 4 features
  • 3 target classes

Step 3: Create a Pandas DataFrame 


df = pd.DataFrame(

    X,

    columns=iris.feature_names

)

df["species"] = pd.Categorical.from_codes(

    iris.target,

    iris.target_names

)

print(df.head())

Expected Result

The first five records of the Iris dataset will be displayed.

10.1 Display Dataset Information 


print("Dataset Shape:")

print(df.shape)

print("\nDataset Information:")

df.info()

print(df.describe())

Visualization helps us understand the data before building a Machine Learning model.

11.1 Histogram

A histogram shows the distribution of numerical features.

    bins=20,

plt.show()

11.2 Box Plot

A box plot helps us understand the spread and distribution of data. 


df.boxplot(

    by="species",

    figsize=(12, 8)

plt.suptitle("")

plt.show()

The following program displays the relationship between sepal length and sepal width.

12. Divide the Dataset into Training and Testing Data

The dataset is divided into:

  • 70% training data
  • 30% testing data

X_train, X_test, y_train, y_test = train_test_split(

    X,

    y,

    test_size=0.30,

    random_state=42,

    stratify=y

)

print("Training samples:", X_train.shape[0])

print("Testing samples:", X_test.shape[0])

Expected Result 


Training samples: 105

Testing samples: 45

13. Feature Scaling

k-NN is a distance-based algorithm. Therefore, feature scaling is useful to ensure that features with larger numerical values do not dominate the distance calculation. 


scaler = StandardScaler()

X_train = scaler.fit_transform(X_train)

X_test = scaler.transform(X_test)

Important Point

The scaler is fitted only on the training data. 


scaler.fit_transform(X_train)

The same scaler is then used to transform the test data. 


scaler.transform(X_test)

This prevents data leakage.

14. Train the k-NN Model

Create a k-Nearest Neighbours classifier with k = 3. 


knn = KNeighborsClassifier(n_neighbors=3)

knn.fit(X_train, y_train)

The model is now trained using the training dataset.

15. Make Predictions

Use the trained model to predict the classes of the test samples. 


y_pred = knn.predict(X_test)

print("Predicted classes:")

print(y_pred)

16. Evaluate the Model

16.1 Accuracy

Accuracy indicates the percentage of correctly classified samples. 


accuracy = accuracy_score(y_test, y_pred)

print("Accuracy:", accuracy)

16.2 Confusion Matrix 


cm = confusion_matrix(y_test, y_pred)

print("Confusion Matrix:")

print(cm)

The rows represent the actual classes and the columns represent the predicted classes.

16.3 Classification Report 


print("Classification Report:")

print(

    classification_report(

        y_test,

        y_pred,

        target_names=iris.target_names

    )

)

The classification report provides:

  • Precision
  • Recall
  • F1-score
  • Support

17. Predict a New Sample

Consider a new flower with the following measurements:

  • Sepal length = 5.1 cm
  • Sepal width = 3.5 cm
  • Petal length = 1.4 cm
  • Petal width = 0.2 cm

new_sample = np.array([

    [5.1, 3.5, 1.4, 0.2]

])

new_sample_scaled = scaler.transform(new_sample)

prediction = knn.predict(new_sample_scaled)

print(

    "Predicted Species:",

    iris.target_names[prediction][0]

)

Expected Result 


Predicted Species: setosa
