FIND-S Algorithm

FIND-S Algorithm

1. Aim

To implement and demonstrate the FIND-S algorithm for finding the most specific hypothesis from a given set of training examples, where the training data is read from a CSV file.

2. Learning Objectives

After completing this practical, students should be able to:

  1. Understand the concept of hypothesis in concept learning.
  2. Understand the FIND-S algorithm.
  3. Identify positive and negative training examples.
  4. Generalize a hypothesis when attribute values differ.
  5. Implement FIND-S using Python and Pandas.
  6. Read training data from a CSV file.

4. Concept of FIND-S

The FIND-S algorithm starts with the most specific hypothesis and gradually generalizes it using positive training examples.

Initial Hypothesis 


h = <∅, ∅, ∅, ∅, ∅, ∅>

Here, ∅ represents the most specific value.

Important Rule

  • Positive example (Yes) → used to update the hypothesis.
  • Negative example (No) → ignored by FIND-S.
  • If the attribute value is different from the current hypothesis, replace it with ?.
  • ? means any value is acceptable.

5. FIND-S Algorithm 


Step 1: Initialize the hypothesis h with the most specific values.

        h = <∅, ∅, ∅, ∅, ∅, ∅>

Step 2: Read each training example.

Step 3: If the example is positive (Yes):

        For each attribute:
            If h[i] = ∅
                Set h[i] = x[i]

            Else if h[i] ≠ x[i]
                Set h[i] = ?

Step 4: If the example is negative (No):
        Do not change the hypothesis.

Step 5: Repeat Steps 2–4 for all training examples.

Step 6: Display the final hypothesis.

6. Python Program

Create a Python file named: 


find_s.py


import pandas as pd

# Read training data from CSV file
df = pd.read_csv("training_data.csv")

# Separate features and target
features = df.iloc[:, :-1]
labels = df.iloc[:, -1]

# Number of attributes
n = len(features.columns)

# Initialize the most specific hypothesis
h = [None] * n

# Process each training example
for i, row in features.iterrows():

    y = labels.iloc[i]

    # FIND-S considers only positive examples
    if y == "Yes":

        for j, value in enumerate(row):

            # First positive example
            if h[j] is None:
                h[j] = value

            # Generalize when values are different
            elif h[j] != value:
                h[j] = "?"

        print(f"After row {i}: {h}")

# Display final hypothesis
print("\nFinal Most-Specific Hypothesis:")
print(h)

8. Program Explanation

  • pd.read_csv("training_data.csv") reads the training data from the CSV file.
  • df.iloc[:, :-1] selects all columns except the last column as the input features.
  • df.iloc[:, -1] selects the last column, EnjoySport, as the target label.
  • The hypothesis is initialized using None, representing the most specific hypothesis before processing the first positive example.
  • FIND-S considers only training examples whose target label is Yes.
  • For the first positive example, the hypothesis is initialized with its attribute values.
  • When a later positive example contains a different value for an attribute, the corresponding hypothesis value is generalized to ?.
  • Negative examples are ignored by the FIND-S algorithm.

9. Observation and Interpretation

The first positive example initializes the hypothesis with its exact attribute values. 


['Sunny', 'Warm', 'Normal', 'Strong', 'Warm', 'Same']

The second positive example differs from the first example in the Humidity attribute. Therefore, the hypothesis for Humidity is generalized to ?. 


['Sunny', 'Warm', '?', 'Strong', 'Warm', 'Same']

The third training example is negative and is therefore ignored by FIND-S.

The fourth example is positive. It differs from the current hypothesis in the Water and Forecast attributes. These attributes are therefore generalized to ?. 


['Sunny', 'Warm', '?', 'Strong', '?', '?']

10. Key Points to Remember

  • FIND-S is a concept-learning algorithm used to find the most specific hypothesis consistent with positive training examples.
  • The algorithm starts with the most specific hypothesis.
  • Only positive training examples are used to update the hypothesis.
  • Negative training examples are ignored.
  • The symbol ? represents any acceptable value.
  • When attribute values differ between positive examples, the hypothesis is generalized.
  • Pandas provides convenient functions for reading and processing CSV datasets.

11. Result

The FIND-S algorithm was successfully implemented using Python and Pandas. The training data was read from a CSV file, and the most specific hypothesis was obtained by considering the positive training examples and generalizing the hypothesis whenever attribute values differed.

The final most-specific hypothesis obtained is: 


['Sunny', 'Warm', '?', 'Strong', '?', '?']
