Practical No. 4

Simple Linear Regression: Modeling the Relationship Between One Independent Variable and One Dependent Variable and Interpreting Slope and Intercept

Unit: II

1. Aim

To build a Simple Linear Regression model in Python to predict a student's Final Marks from their weekly Study Hours and to interpret the slope and intercept of the fitted regression line.

2. Tools / Libraries

  • Python
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn
  • Scikit-learn

The same Student Performance dataset used in Practical No. 3 is reused. This allows students to extend the relationship identified during Exploratory Data Analysis into a predictive regression model.

3. Theory

Simple Linear Regression is a supervised learning technique used to model the relationship between one independent variable and one dependent variable.

The general equation of Simple Linear Regression is:

y = a + bx

where:

  • y = dependent or target variable
  • x = independent or predictor variable
  • a = intercept
  • b = slope or regression coefficient

The slope represents the expected change in the dependent variable for a one-unit increase in the independent variable.

The intercept represents the predicted value of the dependent variable when the independent variable is zero.

The regression line is estimated using the Least Squares Method, which minimizes the sum of the squared differences between the observed values and the values predicted by the regression line.

In this practical:

  • Independent variable (x) = Study Hours
  • Dependent variable (y) = Final Marks

Therefore, the regression equation takes the form:

Final Marks = a + b(Study Hours)

4. Implementation

Step 1 — Create the Dataset

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

data = {
    'Study_Hours': [2, 3, 5, 6, 8,
                    2, 4, 6, 7, 9,
                    3, 4, 5, 7, 8],

    'Final_Marks': [55, 62, 78, 85, 92,
                    50, 68, 82, 88, 94,
                    60, 71, 76, 84, 90]
}

df = pd.DataFrame(data)

print(df.head())
print(df.shape)

Output

The dataset contains 15 rows and 2 columns. The two variables are Study_Hours and Final_Marks. There are no missing values.

Step 2 — Select the Independent and Dependent Variables

# Independent variable
X = df[['Study_Hours']]

# Dependent variable
y = df['Final_Marks']

Here, Study_Hours is the independent variable used to predict Final_Marks.

X is written using double square brackets because Scikit-learn expects the input features in a two-dimensional format.

Step 3 — Visualize the Relationship Using a Scatter Plot

sns.scatterplot(
    x='Study_Hours',
    y='Final_Marks',
    data=df
)

plt.title('Study Hours vs Final Marks')
plt.xlabel('Study Hours per Week')
plt.ylabel('Final Marks')
plt.show()

Graph Interpretation

The scatter plot shows a clear positive and approximately linear relationship between study hours and final marks. In general, students who study for more hours tend to obtain higher final marks.

This relationship suggests that Simple Linear Regression may be appropriate for modelling the relationship between the two variables.

Step 4 — Fit the Simple Linear Regression Model

model = LinearRegression()

# Train the model
model.fit(X, y)

print("Slope (b)     :", round(model.coef_[0], 2))
print("Intercept (a) :", round(model.intercept_, 2))

Output

Slope (b)     : 6.09
Intercept (a) : 43.57

Therefore, the fitted regression equation is approximately:

Final Marks = 43.57 + 6.09(Study Hours)

Step 5 — Interpret the Slope and Intercept

Slope = 6.09

The slope indicates that for every one-hour increase in weekly study time, the predicted final marks increase by approximately 6.09 marks, on average, according to this fitted model.

Intercept = 43.57

The intercept indicates that the model predicts approximately 43.57 marks when study hours are zero.

However, zero study hours are outside the observed range of the dataset, so the intercept should mainly be interpreted as the mathematical baseline required to define the regression line rather than as a realistic prediction.

Step 6 — Draw the Regression Line

sns.scatterplot(
    x='Study_Hours',
    y='Final_Marks',
    data=df
)

plt.plot(
    X,
    model.predict(X),
    color='red',
    label='Regression Line'
)

plt.title('Regression Line: Study Hours vs Final Marks')
plt.xlabel('Study Hours per Week')
plt.ylabel('Final Marks')
plt.legend()
plt.show()

Graph Interpretation

The graph displays the observed data points together with the fitted regression line. The line represents the best linear fit to the observed data according to the Least Squares Method.

Most observations lie relatively close to the regression line, indicating a strong linear relationship in this dataset.

Step 7 — Make a Prediction

# Predict final marks for a student who studies 6 hours per week
hours = [[6]]

predicted_marks = model.predict(hours)

print(
    "Predicted marks for 6 study hours:",
    round(predicted_marks[0], 2)
)

Output

Predicted marks for 6 study hours: 80.14

Interpretation

According to the fitted regression model, a student who studies 6 hours per week is predicted to score approximately 80.14 marks.

The prediction is an estimated value based on the fitted relationship between study hours and final marks.

Step 8 — Evaluate the Regression Model

# Generate predictions for the existing observations
y_pred = model.predict(X)

# Calculate R²
r2 = r2_score(y, y_pred)

# Calculate RMSE
rmse = np.sqrt(mean_squared_error(y, y_pred))

print("R² Score :", round(r2, 2))
print("RMSE     :", round(rmse, 2))

Output

R² Score : 0.95
RMSE     : 2.90

Interpretation of R²

The R² value is approximately 0.95.

This means that approximately 95% of the variation in Final Marks is explained by Study Hours in this fitted model.

The remaining variation is associated with other factors and random variation not represented by this one-predictor model.

Interpretation of RMSE

The RMSE is approximately 2.90 marks.

This indicates that the typical size of the prediction error is about 2.9 marks, measured in the same units as the dependent variable.

Step 9 — Plot the Residuals

# Calculate residuals
residuals = y - y_pred

sns.scatterplot(
    x=y_pred,
    y=residuals
)

plt.axhline(
    0,
    color='red',
    linestyle='--'
)

plt.title('Residual Plot')
plt.xlabel('Predicted Marks')
plt.ylabel('Residuals')
plt.show()

Graph Interpretation

The residual plot displays the differences between the observed and predicted final marks.

The residuals are distributed around the zero line without a strong systematic pattern. This provides visual support for the suitability of a linear relationship for this dataset.

However, a residual plot alone is not sufficient to establish all regression assumptions; it is primarily used here as a basic diagnostic of the fitted linear model.

7. Conclusion

Simple Linear Regression was used to model the relationship between Study Hours and Final Marks.

The fitted model produced the regression equation:

Final Marks = 43.57 + 6.09(Study Hours)

The model achieved an R² value of approximately 0.95 and an RMSE of approximately 2.90 marks for this dataset.

The results indicate a strong positive linear association between study hours and final marks in the sample.

This practical demonstrates how a relationship identified during Exploratory Data Analysis can be converted into a mathematical model for prediction.

It should be noted that regression describes an observed association and does not, by itself, establish a causal relationship.
