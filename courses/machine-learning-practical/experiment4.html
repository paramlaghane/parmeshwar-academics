Practical No. 4

Simple Linear Regression: Modeling the Relationship Between One Independent Variable and One Dependent Variable and Interpreting Slope and Intercept

Unit: II

1. Aim

To build a Simple Linear Regression model in Python to predict a student's Final Marks from their weekly Study Hours and to interpret the slope and intercept of the fitted regression line.

2. Tools / Libraries

  • Python
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn
  • Scikit-learn

The same Student Performance dataset used in Practical No. 3 is reused. This allows students to extend the relationship identified during Exploratory Data Analysis into a predictive regression model.

3. Theory

Simple Linear Regression is a supervised learning technique used to model the relationship between one independent variable and one dependent variable.

The general equation of Simple Linear Regression is:

y = a + bx

where:

  • y = dependent or target variable
  • x = independent or predictor variable
  • a = intercept
  • b = slope or regression coefficient

The slope represents the expected change in the dependent variable for a one-unit increase in the independent variable.

The intercept represents the predicted value of the dependent variable when the independent variable is zero.

The regression line is estimated using the Least Squares Method, which minimizes the sum of the squared differences between the observed values and the values predicted by the regression line.

In this practical:

  • Independent variable (x) = Study Hours
  • Dependent variable (y) = Final Marks

Therefore, the regression equation takes the form:

Final Marks = a + b(Study Hours)

4. Python Program

The following single Python program performs all the major steps of Simple Linear Regression: creating the dataset, fitting the model, calculating the slope and intercept, making a prediction, evaluating the model using R² and RMSE, and displaying the regression and residual plots. 

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score


# Create the dataset
data = {
    'Study_Hours': [2, 3, 5, 6, 8,
                    2, 4, 6, 7, 9,
                    3, 4, 5, 7, 8],

    'Final_Marks': [55, 62, 78, 85, 92,
                    50, 68, 82, 88, 94,
                    60, 71, 76, 84, 90]
}

df = pd.DataFrame(data)


# Select independent and dependent variables
X = df[['Study_Hours']]
y = df['Final_Marks']


# Create and train the model
model = LinearRegression()
model.fit(X, y)


# Get slope and intercept
slope = model.coef_[0]
intercept = model.intercept_


print("Slope (b)     :", round(slope, 2))
print("Intercept (a) :", round(intercept, 2))


# Display regression equation
print(
    f"Regression Equation: Final Marks = "
    f"{intercept:.2f} + {slope:.2f}(Study Hours)"
)


# Make prediction for 6 study hours
hours = [[6]]
predicted_marks = model.predict(hours)

print(
    "Predicted marks for 6 study hours:",
    round(predicted_marks[0], 2)
)


# Generate predictions
y_pred = model.predict(X)


# Calculate R²
r2 = r2_score(y, y_pred)


# Calculate RMSE
rmse = np.sqrt(mean_squared_error(y, y_pred))


print("R² Score :", round(r2, 2))
print("RMSE     :", round(rmse, 2))


# Plot regression line
sns.scatterplot(
    x='Study_Hours',
    y='Final_Marks',
    data=df
)

plt.plot(
    X,
    y_pred,
    color='red',
    label='Regression Line'
)

plt.title('Simple Linear Regression')
plt.xlabel('Study Hours per Week')
plt.ylabel('Final Marks')
plt.legend()
plt.show()


# Calculate residuals
residuals = y - y_pred


# Plot residuals
sns.scatterplot(
    x=y_pred,
    y=residuals
)

plt.axhline(
    0,
    color='red',
    linestyle='--'
)

plt.title('Residual Plot')
plt.xlabel('Predicted Marks')
plt.ylabel('Residuals')
plt.show()

6. Program Explanation

1. Create the Dataset

A small Student Performance dataset is created using Pandas. It contains two variables: Study_Hours and Final_Marks.

2. Select Variables

Study_Hours is selected as the independent variable and Final_Marks is selected as the dependent variable.

3. Train the Model

The LinearRegression() class from Scikit-learn is used to create the model. The fit() method trains the model using the available observations.

4. Interpret Slope

The slope is approximately 6.09. Therefore, for every one-hour increase in weekly study time, the predicted final marks increase by approximately 6.09 marks, on average, according to this fitted model.

5. Interpret Intercept

The intercept is approximately 43.57. It represents the predicted final marks when study hours are zero.

However, zero study hours are outside the observed range of the dataset, so the intercept should mainly be interpreted as the mathematical baseline required to define the regression line rather than as a realistic prediction.

6. Prediction

For a student studying 6 hours per week, the model predicts approximately 80.14 marks.

7. Model Evaluation

The model has an R² value of approximately 0.95. This means that approximately 95% of the variation in Final Marks is explained by Study Hours in this fitted model.

The RMSE is approximately 2.90 marks, indicating that the typical size of the prediction error is about 2.9 marks.

8. Residuals

Residuals represent the differences between the observed and predicted values. A residual plot can be used as a basic diagnostic for examining whether the residuals show a strong systematic pattern.

9. Conclusion

Simple Linear Regression was used to model the relationship between Study Hours and Final Marks.

The fitted model produced the regression equation:

Final Marks = 43.57 + 6.09(Study Hours)

The model achieved an R² value of approximately 0.95 and an RMSE of approximately 2.90 marks for this dataset.

The results indicate a strong positive linear association between study hours and final marks in the sample.

This practical demonstrates how a relationship identified during Exploratory Data Analysis can be converted into a mathematical model for prediction.

It should be noted that regression describes an observed association and does not, by itself, establish a causal relationship.
