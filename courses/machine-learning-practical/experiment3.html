Practical No. 3

Exploratory Data Analysis: Summarizing Distributions and Visualizing Patterns and Relationships using Data Visualization

1. Aim

To perform Exploratory Data Analysis on a dataset by computing summary statistics and generating appropriate visualizations in order to understand the distribution of individual variables and the relationships between them.

2. Objectives

  • To summarize data using measures of central tendency, dispersion, and frequency.
  • To visualize single-variable (univariate) distributions using bar charts, histograms, density plots, and box plots.
  • To compare distributions across groups.
  • To examine relationships between variables using scatter plots, pair plots, and correlation heatmaps.
  • To identify outliers, skewness, and potential patterns before model building.

3. Theory

EDA is the first analytical step after data cleaning. It uses graphical and numerical summaries to reveal the underlying structure of data — how variables are distributed, whether they are skewed, where outliers lie, and how strongly variables are related. Correlation quantifies the linear association between two numeric variables (ranging from −1 to +1), while plots make such patterns visually interpretable. EDA guides the choice of subsequent models and feature selection.

4. Tools / Libraries

Python with Pandas (data handling and summary statistics) and Matplotlib / Seaborn (visualization).

5. Procedure

  1. Load the dataset into a Pandas DataFrame and inspect its structure using .head, .info, and .shape.
  2. Summarize the data using .describe to obtain count, mean, standard deviation, minimum, quartiles, and maximum for numeric columns; use .value_counts for categorical columns.
  3. Draw a Bar Chart to display the frequency of categories in a categorical variable.
  4. Plot a Histogram to show the frequency distribution of a numeric variable.
  5. Plot a Distribution/Density Plot to view the shape (skewness, modality) of a variable's distribution.
  6. Draw a Box Plot to visualize the median, quartiles, and outliers of a numeric variable.
  7. Compare Distributions across groups (e.g., box plots or density plots split by a category).
  8. Draw a Scatter Plot between two numeric variables to observe the nature of their relationship.
  9. Generate a Pair Plot to view pairwise scatter plots and distributions across multiple variables at once.
  10. Compute the Correlation matrix and visualize it using a Heatmap to identify strongly related variables.

6. Expected Outcome

The student will be able to:

  • Interpret summary statistics and identify skewed or outlier-prone variables.
  • Select the correct plot type for a given analytical question.
  • Detect relationships, trends, and correlations between variables.
  • Produce a set of visualizations that support further modeling decisions.

7. Conclusion

Exploratory Data Analysis using summary statistics and visualizations provides a clear understanding of data distribution and inter-variable relationships, forming a reliable foundation for building and evaluating Machine Learning models.
