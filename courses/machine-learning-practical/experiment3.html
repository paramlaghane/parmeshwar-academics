Practical No. 3

Exploratory Data Analysis: Summarizing Distributions and Visualizing Patterns and Relationships Using Data Visualization

1. Aim

To perform Exploratory Data Analysis (EDA) on a dataset using Python by computing summary statistics and generating appropriate visualizations to understand variable distributions, patterns, and relationships.

2. Tools / Libraries Required

  • Python
  • Pandas
  • Matplotlib
  • Seaborn
  • Iris Dataset

3. Implementation

Step 1 — Load the Dataset and Inspect Its Structure

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Load the Iris dataset
df = sns.load_dataset('iris')

# Display the first five rows
print(df.head())

# Display dataset information
print(df.info())

# Display the shape of the dataset
print(df.shape)

Output:

The dataset contains 150 rows and 5 columns. The columns are sepal_length, sepal_width, petal_length, petal_width, and species. The four numerical columns contain floating-point values, while species is a categorical column. The dataset contains no missing values.

Step 2 — Calculate Summary Statistics

# Display summary statistics for numerical columns
print(df.describe())

# Display the frequency of each species
print(df['species'].value_counts())

Output:

The describe() function displays the count, mean, standard deviation, minimum, 25th percentile, median, 75th percentile, and maximum values for each numerical variable.

The value_counts() function shows that setosa, versicolor, and virginica each contain 50 records.

Step 3 — Bar Chart for Categorical Frequency

sns.countplot(x='species', data=df)

plt.title('Count of Each Species')
plt.xlabel('Species')
plt.ylabel('Count')
plt.show()

Graph Interpretation:

The bar chart contains three bars of equal height, with each species having a frequency of 50. This indicates that the Iris dataset has balanced classes.

Step 4 — Histogram for Distribution of a Numerical Variable

sns.histplot(df['sepal_length'], bins=15, kde=True)

plt.title('Histogram of Sepal Length')
plt.xlabel('Sepal Length (cm)')
plt.ylabel('Frequency')
plt.show()

Graph Interpretation:

The histogram shows the frequency distribution of sepal length. The KDE curve provides a smooth representation of the distribution. Most observations are concentrated around the middle range of sepal length.

Step 5 — Density Plot

sns.kdeplot(df['petal_length'], fill=True)

plt.title('Density Plot of Petal Length')
plt.xlabel('Petal Length (cm)')
plt.ylabel('Density')
plt.show()

Graph Interpretation:

The density plot shows the distribution of petal length. The distribution is approximately bimodal, indicating the presence of distinct groups within the dataset corresponding mainly to different Iris species.

Step 6 — Box Plot for Spread and Outliers

sns.boxplot(x=df['sepal_width'])

plt.title('Box Plot of Sepal Width')
plt.xlabel('Sepal Width (cm)')
plt.show()

Graph Interpretation:

The box plot displays the median, interquartile range, and whiskers of sepal width. Individual points beyond the whiskers represent potential outliers.

Step 7 — Grouped Box Plot for Comparing Distributions

sns.boxplot(x='species', y='petal_length', data=df)

plt.title('Petal Length by Species')
plt.xlabel('Species')
plt.ylabel('Petal Length (cm)')
plt.show()

Graph Interpretation:

The box plot compares petal length across the three species. setosa has a substantially smaller petal length than versicolor and virginica. The distributions of versicolor and virginica are higher and show some overlap.

This indicates that petal length is an important variable for distinguishing the species.

Step 8 — Scatter Plot for the Relationship Between Two Variables

sns.scatterplot(
    x='sepal_length',
    y='petal_length',
    hue='species',
    data=df
)

plt.title('Sepal Length vs Petal Length')
plt.xlabel('Sepal Length (cm)')
plt.ylabel('Petal Length (cm)')
plt.show()

Graph Interpretation:

The scatter plot shows the relationship between sepal length and petal length, with different colours representing the three species.

Petal length generally increases as sepal length increases. The species form relatively distinct clusters, particularly for setosa.

Step 9 — Pair Plot for Pairwise Relationships

sns.pairplot(df, hue='species')

plt.show()

Graph Interpretation:

The pair plot displays scatter plots for all pairs of numerical variables and distributions along the diagonal. The observations are coloured according to species.

It provides an overall view of relationships among variables and shows that petal measurements provide particularly good separation between the species.

Step 10 — Correlation Matrix and Heatmap

# Calculate the correlation matrix
corr = df.drop('species', axis=1).corr()

# Display the correlation heatmap
sns.heatmap(corr, annot=True, cmap='coolwarm', fmt='.2f')

plt.title('Correlation Heatmap')
plt.show()

Graph Interpretation:

The heatmap displays the correlation coefficients between the numerical variables. Petal length and petal width show a strong positive correlation.

Sepal width has weaker relationships with the petal measurements. Correlation analysis helps identify variables that may be useful for further analysis and modelling.

After completing this practical, the student will be able to:

  2. Identify the frequency of categorical variables.
  3. Select appropriate visualizations for analysing distributions, comparisons, and relationships.
  4. Detect patterns, skewness, modality, and potential outliers using graphs.
  5. Compare distributions across different categories.
  6. Identify relationships and correlations between numerical variables.
  7. Use Exploratory Data Analysis as a preliminary step for machine learning and statistical modelling.

6. Conclusion

Exploratory Data Analysis (EDA) helps transform raw data into meaningful numerical and visual insights. In this practical, the Iris dataset was analysed using Pandas, Matplotlib, and Seaborn. Summary statistics and different visualizations were used to understand the distribution of variables, compare species, identify potential outliers, examine relationships, and analyse correlations.

The analysis provides a strong foundation for further statistical analysis and machine learning tasks such as regression and classification.
