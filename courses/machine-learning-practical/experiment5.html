Simple Linear Regression: Modeling the Relationship between One Independent and One Dependent Variable and Interpreting Slope and Intercept

Practical No. 5

Title: Simple Linear Regression: Modeling the Relationship between One Independent and One Dependent Variable and Interpreting Slope and Intercept

Unit: II

Aim

To build a Simple Linear Regression model in Python that predicts a student's Final Marks from their weekly Study Hours, and to interpret the slope and intercept of the fitted line.

Concept / Theory

Simple Linear Regression models the relationship between one independent variable (predictor) and one dependent variable (target) as a straight line:

y = a + bx

Where:

  • y = dependent variable
  • x = independent variable
  • b = slope: the change in y for a one-unit increase in x
  • a = intercept: the value of y when x = 0

The line of best fit is obtained by the method of least squares, which minimises the sum of squared vertical distances (residuals) between the observed points and the line.

Assumptions: Linearity of the relationship, independence of observations, constant variance of residuals (homoscedasticity), and normally distributed residuals.

Evaluation measures:

  • R² (coefficient of determination): Proportion of variance in the target explained by the model (0 to 1; higher is better).
  • RMSE: Square root of the average squared error; penalises large errors more heavily.

Algorithm / Procedure

  1. Import the required libraries (Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn).
  2. Load the student dataset into a DataFrame.
  3. Assign the independent variable to X and the dependent variable to y.
  4. Draw a scatter plot to visually confirm a linear relationship.
  5. Create a LinearRegression object and fit it on the data.
  6. Display the slope and intercept and interpret them in context.
  7. Overlay the regression line on the scatter plot.
  8. Predict the target for a new value of the predictor.
  9. Evaluate the model using R² and RMSE.
  10. Plot residuals to check that the linearity assumption holds.

Program / Implementation

import pandas as pd

import numpy as np

import matplotlib.pyplot as plt

import seaborn as sns


from sklearn.linear_model import LinearRegression

from sklearn.metrics import mean_squared_error, r2_score


# Step 1-2: Create the academic dataset (15 students)

data = {
    'Study_Hours': [2, 3, 5, 6, 8, 2, 4, 6, 7, 9, 3, 4, 5, 7, 8],
    'Final_Marks': [55, 62, 78, 85, 92, 50, 68, 82, 88, 94, 60, 71, 76, 84, 90]
}

df = pd.DataFrame(data)

print(df.head())
print(df.shape)                     # (15, 2)


# Step 3: Define predictor and target

X = df[['Study_Hours']]             # must be 2-D for sklearn

y = df['Final_Marks']


# Step 4: Visualize the relationship

sns.scatterplot(x='Study_Hours', y='Final_Marks', data=df)

plt.title('Study Hours vs Final Marks')
plt.xlabel('Study Hours per Week')
plt.ylabel('Final Marks')

plt.show()


# Step 5-6: Fit the model and print slope and intercept

model = LinearRegression()

model.fit(X, y)

print("Slope (b)     :", round(model.coef_[0], 2))
print("Intercept (a) :", round(model.intercept_, 2))


# Step 7: Draw the regression line

sns.scatterplot(x='Study_Hours', y='Final_Marks', data=df)

plt.plot(X, model.predict(X), color='red')

plt.title('Regression Line: Study Hours vs Final Marks')

plt.show()


# Step 8: Predict for a new value

print("Predicted marks for 6 study hours:",
      round(model.predict([[6]])[0], 2))


# Step 9: Evaluate the model

y_pred = model.predict(X)

print("R2   :", round(r2_score(y, y_pred), 2))

print("RMSE :", round(np.sqrt(mean_squared_error(y, y_pred)), 2))


# Step 10: Residual plot

residuals = y - y_pred

sns.scatterplot(x=y_pred, y=residuals)

plt.axhline(0, color='red', linestyle='--')

plt.xlabel('Predicted Marks')
plt.ylabel('Residuals')
plt.title('Residual Plot')

plt.show()

Fitted equation

Interpretation of slope and intercept

  • Slope = 6.09 → Each additional hour of study per week raises final marks by about 6.09 marks, on average.
  • Intercept = 43.57 → The model predicts about 43.57 marks for a student studying 0 hours. This is only a mathematical anchor for the line, not a realistic scenario.
  • Prediction for 6 hours = 80.14 — consistent with the two students in the dataset who studied 6 hours and scored 85 and 82.
  • R² = 0.95 → About 95% of the variation in final marks is explained by study hours alone.
  • RMSE = 2.90 → Predictions differ from actual marks by about 2.9 marks on average.

Graphs displayed

  1. Scatter plot — points form a clear upward, near-linear trend, justifying the use of linear regression.
  2. Regression line plot — a red straight line passes through the centre of the points; most points lie close to it, confirming a strong fit.
  3. Residual plot — residuals are scattered randomly above and below the zero line with no pattern, indicating the linearity assumption is satisfied.

(The values above are those produced by running this script on the 15-student dataset. Since plot images can't be rendered here, each graph is described by what it displays — running the code in Jupyter/Colab produces all three graphs.)

Result

A Simple Linear Regression model was successfully fitted with Study Hours as the independent variable and Final Marks as the dependent variable. The model produced a slope of 6.09 and an intercept of 43.57, giving the equation Final Marks = 43.57 + 6.09 × Study Hours. Evaluation on the data yielded R² = 0.95 and RMSE = 2.90, and the residual plot showed no systematic pattern, confirming that a straight line adequately describes the relationship.

Conclusion

Simple Linear Regression quantified the relationship between study hours and final marks, showing that marks rise by roughly 6.09 for every extra study hour and that the model explains about 95% of the variation in performance. The practical demonstrates how a correlation observed during EDA is converted into a usable predictive equation, and how the slope and intercept are interpreted in the context of the problem. It also highlights the key limitation that regression measures association, not causation — higher study hours are associated with higher marks, but the model alone does not prove that study hours cause the improvement.
