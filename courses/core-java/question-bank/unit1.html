Chapter 1: An Introduction to Java

  1. Q. No.: 1   What is Java? Describe its origin and briefly discuss the major stages in its development.
  2. Q. No.: 2   Identify any five important features (buzzwords) of Java and briefly describe each one.
  3. Q. No.: 3   Describe any four Java buzzwords and illustrate each with an appropriate example.
  4. Q. No.: 4   Compare Java and C++ by explaining the major differences between the two programming languages.
  5. Q. No.: 5   Describe the structure of a basic Java program, explaining the role of the class and the main() method. Show how this structure relates to object-oriented programming with an example.
  6. Q. No.: 6   Develop a Java program that prints "Hello World". Describe the procedure for compiling and executing the program and explain the purpose of each line of code.
  7. Q. No.: 7   Classify the primitive data types in Java and explain the memory size and default value associated with each type.
  8. Q. No.: 8   Write a Java program to create a one-dimensional array, assign values to its elements, and print all the elements.
  9. Q. No.: 9   Develop a Java program that initializes a two-dimensional array representing a matrix and displays its elements in matrix form.
  10. Q. No.: 10   Examine the reasons why Java is considered platform-independent. Explain how this property enables Java programs to run on different operating systems.
