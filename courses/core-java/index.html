Core Java

Theory Course

Course Overview

Core Java provides the foundation for object-oriented programming using the Java language. This course introduces students to Java syntax, classes, objects, inheritance, interfaces, exception handling, packages, and file handling. It prepares learners to develop robust, platform-independent applications while building a strong understanding of object-oriented software development principles.

Pre-requisites

  • Knowledge of C or C++ programming is helpful but not mandatory.
  • Basic understanding of programming concepts.
  • Logical thinking and problem-solving skills.
  • Interest in object-oriented programming.

Course Objectives

  • Understand Java programming fundamentals.
  • Learn object-oriented programming concepts using Java.
  • Develop reusable software using classes and objects.
  • Implement inheritance, interfaces, packages, and exception handling.
  • Prepare students for advanced Java technologies.

Course Outcomes

  • CO1: Use an IDE to write, compile, execute, and debug Java programs.
  • CO2: Solve real-world problems using object-oriented programming concepts.
  • CO3: Apply inheritance, interfaces, and polymorphism in Java applications.
  • CO4: Design classes, objects, and relationships to build software solutions.

Course Contents

Unit 1 – Introduction to Java

Study Time: 6 Hours

Learning Objectives

  • Understand the history, features, and platform-independent nature of Java, and compare Java with C++.
  • Learn the Java development environment, including JDK, JVM, JRE, Java IDEs (Eclipse/NetBeans), and development tools such as jdb, javap, and javadoc.
  • Write, compile, and execute simple Java programs while understanding comments, data types, variables, constants, and arrays.
  • Develop a strong foundation in Java programming syntax and basic program structure.
Study Unit →

Unit 2 – Objects and Classes

Study Time: 8 Hours

Learning Objectives

  • Create classes and objects while understanding constructors, constructor overloading, and the use of the this keyword.
  • Apply access specifiers, static members, static blocks, arrays of objects, and inner classes in Java programs.
  • Use predefined classes, wrapper classes, and important methods of the Object class such as equals(), toString(), hashCode(), and getClass().
  • Organize Java applications using packages and understand their creation, import, and usage.
Study Unit →

Unit 3 – Inheritance and Interface

Study Time: 8 Hours

Learning Objectives

  • Understand inheritance using the extends keyword and distinguish between superclass and subclass relationships.
  • Apply method overriding, runtime polymorphism, and the super keyword in Java programs.
  • Learn the use of final, abstract classes, and abstract methods for designing reusable software components.
  • Design flexible applications by defining and implementing Java interfaces.
Study Unit →

Unit 4 – Exception Handling, Strings, Streams and Files

Study Time: 8 Hours

Learning Objectives

  • Understand Java exceptions, checked and unchecked exceptions, and implement robust exception handling using try, catch, throw, throws, and custom exceptions.
  • Work with the String and StringBuffer classes for efficient text manipulation and formatting.
  • Learn the basics of Java streams and file handling for reading and writing data.
  • Develop reliable Java applications using proper error handling and input/output techniques.
