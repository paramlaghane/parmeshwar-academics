Assessment Parameter 2: Conceptual Problem Solving

Question

Create a Java class named Student to represent the details of a student. The class should contain the following data members:

  • Student Name
  • Roll Number
  • Course
  • Semester
  • CGPA

The class should also contain the following member functions:

  • A parameterized constructor to initialize all data members.
  • A method displayDetails() to display all student information.

Finally, create two Student objects in the main() method using the new keyword and display their complete details.

Answer the following sub-parts.

Your program must demonstrate the use of:

  • Class
  • Objects
  • Instance variables
  • Parameterized constructor
  • Methods
  • this keyword
  • Object creation using the new keyword

Conceptual Questions

Answer the following:

  1. What is a class?

  2. What is an object?

  3. What is the purpose of the this keyword?

  4. Why is the new keyword used while creating an object?

Write your answers in one or two sentences each.

Program Requirements

The Java program should:

  1. Define a class named Student.
  2. Declare the required instance variables.
  3. Define a parameterized constructor to initialize the instance variables.
  4. Use the this keyword where required.
  5. Define the displayDetails() method.
  6. Create two Student objects using the new keyword inside main().
  7. Display the complete details of both students.

Expected Program Structure 

class Student {

    // Instance variables

    // Parameterized constructor

    // displayDetails() method

}


public class Main {

    public static void main(String[] args) {

        // Create first Student object

        // Create second Student object

        // Display student details

    }

}

Concepts to be Demonstrated

Concept Where it is Demonstrated
Class Student class
Objects Two Student objects
Instance Variables Student Name, Roll Number, Course, Semester and CGPA
Parameterized Constructor Initializes all student details
Methods displayDetails()
this Keyword Refers to the current Student object
new Keyword Used for creating Student objects

Submission Instructions

  • Write the complete Java program according to the given requirements.
  • Create two Student objects and display their complete details.
  • Ensure that the program demonstrates all the specified Core Java concepts.
  • Answer all four conceptual questions in one or two sentences each.
  • Use proper indentation and meaningful variable names.
  • Write your Name, Roll Number, Class and Assessment Parameter at the top of the submission.
