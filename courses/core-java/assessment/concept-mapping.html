Assessment Component 1 – Concept Mapping

Assessment Component 1

Concept Mapping

Course : Core Java

Assessment Type : Internal Assessment

Activity : Concept Mapping

Question

Prepare a Concept Map on any ONE topic from the course syllabus.

Choose any ONE topic from the syllabus and prepare a neat, well-organized concept map showing the relationships among concepts. Your concept map should use appropriate connectors, arrows, hierarchical organization, and examples wherever applicable.

Guidelines

  1. Use clear boxes, circles, or ellipses to represent every concept. The text inside each shape should be clear and easy to read.
  2. Place the most general concept at the top of the concept map. Arrange related concepts below it in a hierarchical order, moving from general concepts to more specific concepts.
  3. Every connecting line between two concepts must include a meaningful linking phrase (typically one to five words) that clearly explains the relationship.
  4. Use directional arrows to indicate the direction of the relationship between concepts.
  5. Include at least one cross-link (using a dashed or dotted line) that connects two different branches of the concept map to show relationships between concepts in different sections.
  6. Wherever appropriate, include at least one real-world example and connect it to the related concept using an "Instance of" relationship.
  7. Draw the concept map neatly. Avoid overwriting, overlapping shapes, or unlabeled connecting lines.
  8. Write the selected topic as the title at the top of the page.

Note

A concept map is a two-dimensional graphical representation of knowledge in which concepts are placed inside nodes (such as boxes or circles) and connected using labeled links that describe the relationships between them. Concept maps help organize knowledge, improve understanding of complex topics, and illustrate how different concepts are interconnected.

Submission Instructions

  • Select any ONE topic from the Core Java syllabus.
  • Prepare the concept map on an A4 size sheet or using any concept mapping software.
  • Use proper hierarchy, linking phrases, directional arrows and cross-links.
  • Include at least one real-world example wherever applicable.
  • Write your Name, Roll Number, Class and Topic at the top of the sheet.
  • Submit the assignment before the scheduled internal assessment date.
