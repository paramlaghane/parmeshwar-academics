Question 1 – Propositional Logic and Inference

A smart home security system monitors different devices and sensors. The following propositional variables are defined:

Propositional Variables

Symbol Meaning
H It is Hot
M It is Humid
A Alarm is Activated
D Door is Open
P Phone Rings
W Wi-Fi is Working
L Lights are Working

(a) Translation into Propositional Logic

Translate each of the following English statements into Propositional Logic using the logical operators ∧, ∨, ¬, →, and ↔.

No. English Statement Propositional Logic
(i) It is hot but not humid today.
(ii) If the alarm is activated, then either the door opens or the phone rings.
(iii) Neither the Wi-Fi nor the lights are working.

Question 2 – First-Order Logic

Translate the following English statements into First-Order Logic (Predicate Logic) using suitable predicates together with the quantifiers ∀ (for all) and ∃ (there exists).

No. English Statement First-Order Logic
(a) All cats are mammals.
(b) Some birds cannot fly.
(c) Every student loves some subject.

Logical Operators

  • ∧ – AND
  • ∨ – OR
  • ¬ – NOT
  • → – IMPLIES
  • ↔ – IF AND ONLY IF

Quantifiers

  • ∀ – For all
  • ∃ – There exists

Submission Instructions

  • Translate each English statement into the appropriate logical representation.
  • Use the given propositional symbols for Question 1.
  • Use suitable predicates and quantifiers for Question 2.
  • Use appropriate logical operators in propositional logic expressions.
  • Use ∀ and ∃ appropriately in First-Order Logic expressions.
  • Write your Name, Roll Number, Class and Assessment Component at the top of the submission.
