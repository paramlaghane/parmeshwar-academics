Case Study 1 — Traffic Jam Prediction with Bayes' Theorem

Scenario

A traffic app uses past data:

  • P = 0.3 — the prior probability that it rains on any given day.
  • If it rains, the probability of a traffic jam is 0.8.
  • If it does not rain, the probability of a traffic jam is 0.2.

Tasks

  1. Identify the prior, the likelihood, and the posterior in this problem — which number is which?
  2. Compute P — the overall probability of a jam — using the total probability formula: 
    
P(Jam) =
P(Jam | Rain) × P(Rain)
+
P(Jam | No Rain) × P(No Rain)
  3. The app observes a traffic jam. Compute P(Rain | Jam) using Bayes' theorem. 
    
P(Rain | Jam)
=
[P(Jam | Rain) × P(Rain)]
--------------------------
        P(Jam)
  4. In one sentence: why is P(Rain | Jam) larger than P?

Case Study 2 — Holiday → Beach → Ice-Cream: A Simple Bayesian Network

Scenario

A snack shop owner wants to predict ice-cream sales. She builds a Bayesian Network with three nodes: Holiday (H), Beach Visit (V), and Ice-Cream Sales (I). The relationships and Conditional Probability Tables are:

Conditional Probability Tables

Holiday P(H)
Yes 0.5
No 0.5

Holiday P(Beach = Yes)
Yes 0.8
No 0.2

Beach P(Ice-Cream = Yes)
Yes 0.9
No 0.1

Tasks

  1. Draw the DAG (nodes and arrows) and name the parent and child nodes.
  2. Write the CPTs in your own table form and check that they are valid (each row sums to 1).
  3. Compute P(Ice-Cream = Yes).
  4. The shop observes ice-cream sales = Yes (evidence). Compute P(Beach = Yes | Ice-Cream = Yes). What was P(Beach = Yes) before the evidence, and what is it after?

Case Study 3 — Types of Learning + K-Means Clustering

Scenario

Part A

For each situation, name the type of learning: supervised, unsupervised, semi-supervised, or reinforcement.

  1. Predicting house prices from past sales (price labels are known).
  2. Grouping customers into segments without any labels.
  3. Training on 100 labelled photos + 9,000 unlabelled photos.
  4. A robot learning to walk, rewarded for each successful step.
  5. Classifying emails as spam/not spam using labelled examples.

Part B

Five points: A, B, C, D, E. Run one iteration of K-Means with k = 2 and initial centroids C1 =, C2 =.

Tasks (10 marks)

  1. Name the learning type for each of the 5 situations in Part A.
  2. Assign each point to the nearer centroid — show the distances.
  3. Compute the new centroids after the assignment.

Case Study 4 — Evaluating a Spam Filter

Scenario

A spam filter is tested on 100 emails: 35 are actually spam, 65 are actually normal. The filter says "spam" for 35 emails, of which 30 are correctly spam. It wrongly calls 5 normal emails "spam", and it misses 5 spam emails.

Tasks

  1. Build the confusion matrix from the description: fill in TP, TN, FP, FN with the correct numbers.
  2. Compute accuracy, precision, and recall.
  3. Compute the F1-score.
  4. The same model scores 98% on training data but only 70% on test data. Name this problem and suggest one fix.
