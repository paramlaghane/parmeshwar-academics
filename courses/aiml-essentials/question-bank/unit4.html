Unit 4 Question Bank

Unit 4 — Machine Learning

  1. Q. No.: 1  : What is machine learning? Provide one example of a machine learning task and mention one difference between traditional programming and machine learning.
  2. Q. No.:2   Explain supervised learning with one suitable example. Mention any two tasks that can be performed using supervised learning.
  3. Q. No.: 3  What is unsupervised learning? Explain it with one example and mention one task for which it is commonly used.
  4. Q. No.:4   Compare supervised learning and unsupervised learning by stating any two differences.
  5. Q. No.: 5   Explain the terms accuracy, precision, and recall. Given a confusion matrix with TP = 45, FP = 5, FN = 15, and TN = 35, calculate the values of all three metrics.
  6. Q. No.: 6   Explain the importance of data preprocessing before training a machine learning model. Mention any two preprocessing techniques.
  7. Q. No.: 7   What is linear regression? Write the equation of a straight line and explain the significance of its slope and intercept.
  8. Q. No.: 8   Define logistic regression and explain why linear regression is not appropriate for solving classification problems.
  9. Q. No.: 9  Define a decision tree and a random forest. State one major difference between these two machine learning methods.
  10. Q. No.: 10  Explain the concept of clustering and mention one difference between K-Means clustering and hierarchical clustering.
