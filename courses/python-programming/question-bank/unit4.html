Chapter 4: Lists, Tuples, Sets and Dictionaries

  1. Q. No.: 1   Define a list in Python. Explain how to create, initialize and access list elements with suitable examples.
  2. Q. No.: 2   Describe list concatenation and repetition with one example each. Write a program to combine two lists into a single list.
  3. Q. No.: 3   Write a Python program that uses a list comprehension to generate the squares of integers from 1 to 10.
  4. Q. No.: 4   Describe the sort() and reverse() list methods with examples. Write a program to arrange five numbers in ascending order and then reverse their order.
  5. Q. No.: 5   Define a tuple in Python. Explain tuple immutability with an example that demonstrates the result of attempting to modify one of its elements.
  6. Q. No.: 6   Describe how to create, initialize and access a tuple. Explain the functions len(), max(), min() and tuple() with one example each.
  7. Q. No.: 7   Explain the set operations membership testing, union, intersection, difference and symmetric difference with suitable examples.
  8. Q. No.: 8   Explain the key-value pair concept in dictionaries. Write a program to create a dictionary containing the marks of three students and retrieve one student's marks using the corresponding key.
  9. Q. No.: 9   Explain how to traverse a dictionary, add new entries, modify existing values and delete an entry, using one example for each operation.
  10. Q. No.: 10   Explain the dictionary methods len, clear, get, items, keys, values and update with examples. Also state what has_key did in Python 2 and why it is not used in Python 3.
