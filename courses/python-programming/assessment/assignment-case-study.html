Case Study 1 — Student Marks and Grade Calculator

Problem Scenario

A college wants to develop a simple Python program to calculate a student's total marks, percentage, and grade based on marks obtained in different subjects.

The program should accept the student's name and marks in five subjects as input and calculate the total marks and percentage. Based on the percentage, an appropriate grade should be displayed.

Task

Develop a Python program that:

  1. Accepts the student's name and marks in five subjects.
  2. Calculates the total marks.
  3. Calculates the percentage.
  4. Displays the student's name, total marks, and percentage.
  5. Displays a grade using suitable conditions, for example:
    • 75% and above → Distinction
    • 60–74% → First Class
    • 50–59% → Second Class
    • 40–49% → Pass
    • Below 40% → Fail
  6. Display the output in a clear and meaningful format.

Python Concepts Involved

Variables, data types, input/output, operators, expressions, assignment statements, and basic conditional expressions.

Case Study 2 — Electricity Bill Calculator

Problem Scenario

An electricity distribution company wants a simple Python program to calculate the electricity bill of a consumer based on the number of units consumed.

The billing system uses different rates for different consumption levels.

Task

Develop a Python program that:

  1. Accepts the consumer's name and number of electricity units consumed.
  2. Calculates the bill using the following tariff:
Units Consumed Rate
First 100 units ₹2 per unit
Next 100 units ₹3 per unit
Next 300 units ₹5 per unit
Above 500 units ₹7 per unit
  1. Uses conditional statements to determine the applicable charges.
  2. Create a user-defined function to calculate the electricity bill.
  3. Display the consumer's name, units consumed, and final bill amount.
  4. Test the program using at least three different inputs.

Python Concepts Involved

if-else, nested conditions, functions, parameters, return values, arithmetic operators, and input/output.

Case Study 3 — Student Text Analysis and Error Handling

Problem Scenario

A college wants to analyze feedback provided by students. The feedback is entered as a text string, and the system should generate some basic information about the text.

The program should also handle invalid input appropriately.

Task

Develop a Python program that:

  1. Accepts a sentence or feedback message from the user.
  2. Displays:
    • Number of characters
    • Number of words
    • Number of vowels
    • Number of digits
    • Number of uppercase letters
    • Number of lowercase letters
  3. Searches for a word or substring entered by the user.
  4. Replaces a specified word with another word.
  5. Converts the feedback into lowercase and uppercase forms.
  6. Uses exception handling (try-except) to handle an appropriate input error.
  7. Displays the results clearly.

Python Concepts Involved

Strings, indexing, slicing, string methods, split(), find(), replace(), lower(), upper(), loops, and exception handling.

Case Study 4 — Student Record Management Using Lists and Tuples

Problem Scenario

A college wants to maintain basic student information using Python. The system should store student names and marks and provide simple operations for analyzing the records.

Task

Develop a Python program that:

  1. Creates a list containing student names.
  2. Creates a corresponding list of marks.
  3. Allows a new student to be added.
  4. Allows an existing student's marks to be updated.
  5. Sorts the marks in ascending and descending order.
  6. Finds the highest and lowest marks.
  7. Calculates the number of students and average marks.
  8. Uses a tuple to store the fixed details of a student, such as:
    • Roll number
    • Name
    • Course
  9. Demonstrates at least one list slicing or list comprehension operation.
  10. Displays the final student records.
