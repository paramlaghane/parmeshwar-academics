Assessment Parameter 2

Conceptual Problem Solving

Course : Python Programming

Assessment Type : Internal Assessment

Activity : Conceptual Problem Solving

Question

The BCA Department is developing a Python program to automate the analysis of classroom test results. The marks obtained by students in a class are stored in the following list: 

marks = [85, 42, -1, 67, 33, 999, 90, 51, 28]

The program must follow the rules given below.

Rules

Rule No. Rule Purpose
1 A negative value indicates that the student was Absent. It should be skipped and counted as Absent, not as Fail.
2 Marks are classified as:

• Excellent: 80 and above
• Good: 60–79
• Average: 40–59
• Fail: Below 40 		Used for student performance analysis.
3 The value 999 is a sentinel value. It indicates the end of valid data, and the program must stop processing further elements.

As a Python programmer, you are required to develop a solution that demonstrates the proper use of Python's conditional statements and looping constructs.

Your program should include the following concepts:

  • if-elif-else
  • Nested control structure (nested if-else or nested loop)
  • for loop with range()
  • break
  • continue

(a) Program Development

Write a complete Python program that performs the following tasks:

  1. Traverse the marks list using for with range(len(marks)).
  2. Use the continue statement to skip negative values and count them as Absent.
  3. Use the break statement to terminate the loop immediately when the sentinel value 999 is encountered.
  4. Classify each valid mark using an if-elif-else statement into one of the following categories:
  • Excellent
  • Good
  • Average
  • Fail
  1. Display the total number of students in each category in the following format:

Output Format 

Excellent : ___
Good      : ___
Average   : ___
Fail      : ___
Absent    : ___

(b) Understanding break and continue (1 Mark)

Using the same marks list, explain the practical difference between the break and continue statements.

Concepts to be Demonstrated

Concept Application in the Problem
if-elif-else Classify valid marks as Excellent, Good, Average or Fail.
Nested control structure Use a nested if-else or nested loop as required.
for loop with range() Traverse the list using range(len(marks)).
continue Skip negative marks after counting the student as Absent.
break Stop processing when the sentinel value 999 is encountered.

Submission Instructions

  • Write the complete Python program according to the given requirements.
  • Use the given marks list for testing the program.
  • Use proper indentation and meaningful variable names.
  • Demonstrate all the specified Python concepts in the program.
  • Display the total number of students in each category in the required format.
  • Answer the question on the practical difference between break and continue.
  • Write your Name, Roll Number, Class and Assessment Parameter at the top of the submission.
