Python Programming

Theory Course

Course Overview

Python is one of the world's most popular programming languages due to its simplicity, readability, and extensive libraries. It is widely used in software development, web applications, data science, artificial intelligence, automation, and scientific computing. This course introduces students to Python programming from the fundamentals of programming through advanced data structures and exception handling, providing a strong foundation for software development and emerging technologies.

Pre-requisites

  • Basic understanding of programming concepts.
  • Ability to understand algorithms and logical thinking.
  • Interest in learning modern programming languages.
  • Basic computer operating skills.

Course Objectives

  • Understand Python programming language fundamentals.
  • Develop problem-solving skills using Python.
  • Write efficient and reusable Python programs.
  • Build confidence in software development using Python.
  • Prepare students for Data Science, Artificial Intelligence, and Web Development.

Course Outcomes

  • CO1: Understand the importance of Python for software development.
  • CO2: Develop the ability to write Python programs for solving computational problems.
  • CO3: Gain practical programming experience using Python.
  • CO4: Develop projects suitable for web, data science, broadcast, and social media applications.

Course Contents

Unit 1 – Introduction to Python

Study Time: 6 Hours

Learning Objectives

  • Understand Python as an interpreted, high-level programming language and learn the differences between interactive mode and script mode.
  • Learn variables, data types, keywords, operators, expressions, statements, and operator precedence.
  • Develop Python programs using assignment statements, user input, output, and comments.
  • Build simple Python applications using arithmetic, relational, and logical operators.
Study Unit →

Unit 2 – Conditional Statements, Loops and Functions

Study Time: 8 Hours

Learning Objectives

  • Implement decision-making using if, if-else, nested if statements, and compound conditional expressions.
  • Develop programs using while loops, for loops, nested loops, range(), break, continue, and pass statements.
  • Understand Python modules and use built-in functions from the math, random, and datetime libraries.
  • Design reusable programs using user-defined functions, parameters, keyword arguments, default values, return values, and variable scope.
Study Unit →

Unit 3 – Strings and Exception Handling

Study Time: 8 Hours

Learning Objectives

  • Create, initialize, access, slice, and manipulate strings using Python operators and built-in methods.
  • Use commonly used string functions including len(), find(), replace(), split(), join(), upper(), lower(), count(), and swapcase().
  • Understand syntax errors, runtime exceptions, and techniques for handling exceptions in Python.
  • Develop reliable programs using try, except, finally, raise, and user-defined exceptions.
Study Unit →

Unit 4 – Lists, Tuples, Sets and Dictionaries

Study Time: 8 Hours

Learning Objectives

  • Create and manipulate lists using indexing, slicing, list comprehensions, and built-in list methods.
  • Understand tuples as immutable data structures and use tuple functions for data storage and processing.
  • Perform set operations including union, intersection, difference, symmetric difference, and membership testing.
  • Create, update, traverse, and manage dictionaries using key-value pairs and common dictionary methods.
Study Unit →
