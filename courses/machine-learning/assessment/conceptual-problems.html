Activity : Conceptual Problem Solving

Scenario

A regional bank, wants to improve its business operations using Machine Learning (ML). The bank has identified three important business problems that need intelligent, data-driven solutions.

The available data for each problem is given below.

Business Problems and Available Data

Problem No. Business Problem Available Data
1 Detect fraudulent credit card transactions in real time (approximately 10,000 transactions per day). Historical transaction records are available, and each transaction is labelled as Fraud or Legitimate.
2 Group 50,000 customers into meaningful customer segments for targeted marketing campaigns. Customer demographic and purchasing information is available, but no predefined customer segment labels exist.
3 Predict whether a home loan applicant is likely to default on loan repayment. Historical loan records are available, and each loan is labelled as Defaulted or Repaid.

The bank has informed you that they require a Machine Learning solution, not merely data analysis or reporting.

Questions

(a) Understanding the Basics

Define the following terms in one concise sentence each:

  1. Analytics

  2. Machine Learning

Also, state one clear point of difference between Analytics and Machine Learning.

(b) Selecting the Appropriate Machine Learning Approach

For each of the three business problems described in the case study:

  • Identify the most suitable type of Machine Learning.
  • Select the appropriate category from the following:
  • Supervised Learning
  • Unsupervised Learning
  • Reinforcement Learning

Provide one valid reason to justify your choice.
