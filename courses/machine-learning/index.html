Machine Learning

Theory Course

Course Overview

Machine Learning is one of the most important areas of Artificial Intelligence that enables computers to learn patterns from data and make intelligent predictions without being explicitly programmed. This course introduces students to supervised and unsupervised learning techniques, regression, classification, clustering, dimensionality reduction, and modern machine learning libraries such as Scikit-Learn. Through theoretical concepts and practical examples, students gain the knowledge required to build and evaluate machine learning models for real-world applications.

Pre-requisites

  • Basic knowledge of Data Mining and Data Warehousing.
  • Basic programming knowledge.
  • Fundamental understanding of statistics is helpful.
  • Interest in data analysis and predictive modeling.

Course Objectives

  • Introduce the basic concepts and techniques of Machine Learning.
  • Understand regression, classification, and clustering methods.
  • Develop the ability to build predictive machine learning models.
  • Learn modern machine learning tools and frameworks.

Course Outcomes

  • CO1: Become familiar with dimensionality reduction techniques.
  • CO2: Identify suitable machine learning techniques for different types of problems.
  • CO3: Design, implement, evaluate, and interpret machine learning models for regression, classification, and clustering.
  • CO4: Understand data clustering techniques and their practical applications.

Course Contents

Unit 1 – Introduction to Machine Learning & Descriptive Analytics

Study Time: 6 Hours

Learning Objectives

  • Understand the fundamentals of Machine Learning, its types, applications, development framework, and modern ML tools.
  • Learn the importance of analytics and data preprocessing before building machine learning models.
  • Explore data using Python DataFrames and handle missing values effectively.
  • Visualize datasets using bar charts, histograms, box plots, scatter plots, pair plots, and heatmaps to discover meaningful patterns.
Study Unit →

Unit 2 – Linear Regression

Study Time: 8 Hours

Learning Objectives

  • Understand regression analysis and its importance in predictive modeling.
  • Build Simple Linear Regression models using real-world datasets.
  • Evaluate regression models using model diagnostics and performance measures.
  • Extend regression analysis to Multiple Linear Regression for solving complex prediction problems.
Study Unit →

Unit 3 – Classification and Clustering

Study Time: 8 Hours

Learning Objectives

  • Understand classification techniques including Binary Logistic Regression and Decision Tree Learning.
  • Evaluate classification models using Gain Charts and Lift Charts.
  • Learn the principles of clustering and discover hidden patterns within datasets.
  • Apply K-Means and Hierarchical Clustering techniques to create meaningful data segments.
Study Unit →

Unit 4 – Advances in Machine Learning

Study Time: 8 Hours

Learning Objectives

  • Understand the Gradient Descent optimization algorithm used in machine learning.
  • Develop machine learning models using the Scikit-Learn library.
  • Learn the working principles of K-Nearest Neighbors (KNN) and Random Forest algorithms.
  • Compare modern machine learning algorithms and select suitable models for different predictive tasks.
