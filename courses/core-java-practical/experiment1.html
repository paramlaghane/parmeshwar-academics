Practical No. 01

Broadcast a Program to Print "Hello World" on the Screen

1.1 Program 1A – Simplest Java Program 


public class HelloWorld {

    public static void main(String[] args) {

        System.out.println("Hello, World!");

    }

}

Line-by-Line Dissection

Line 1 


public class HelloWorld {

Declares a public class named HelloWorld. Since it is a public class, the filename must be HelloWorld.java.

Line 2 


public static void main(String[] args) {

This is the entry point of every Java application. It consists of five parts:

  • public – Allows the JVM to access this method.
  • static – Allows the method to be called without creating an object.
  • void – Indicates that the method does not return any value.
  • main – The special method name that the JVM looks for to start program execution.
  • String[] args – An array of strings used to receive command-line arguments.

Line 3 


System.out.println("Hello, World!");

Prints the text "Hello, World!" on the screen and moves the cursor to the next line.

Line 4 


}

Closes the main() method.

Line 5 


}

Closes the HelloWorld class.

public class HelloBCA {

    public static void main(String[] args) {

        String name = "Param";

        System.out.println("Hello, World!");

        System.out.println("Java is simple.");

    }

}

1.3 Using Command-Line Arguments 


public class HelloArg {

    public static void main(String[] args) {

        // args[0] is the first command-line argument

        if (args.length > 0) {

            System.out.println("Hello, " + args[0] + "!");

        } else {

            System.out.println("Hello, World!");

        }

    }

}

Note

args[0] represents the first command-line argument entered after the class name.

Running the Program

Example 1 


java HelloArg

Output 


Hello, World!

8.1 Open the Command Prompt

Compile the Program 


C:\BCA\Java\Practical1> javac HelloWorld.java

The command javac is the Java compiler.

If the program contains no syntax errors, the compiler displays no message and returns directly to the command prompt.

A new file named HelloWorld.class is created in the same folder.

To run a Java program, the source code must first be compiled into a .class file containing Java bytecode. The Java Virtual Machine (JVM) then interprets and executes this bytecode.

Run the Program
