Practical No. 06

Count Letters, Spaces, Digits and Other Characters

1. Aim

To write a Java program to accept a string from the user and count the number of letters, spaces, digits, and other characters present in the string.

2. Theory

A String is a sequence of characters. In Java, individual characters of a string can be accessed using the charAt() method.

To count different types of characters, the program examines each character one by one and places it into one of four categories:

  1. Letter → alphabets such as A–Z and a–z
  2. Digit → numbers such as 0–9
  3. Space → blank space ' '
  4. Other character → symbols and punctuation such as @, #, !, ., -, etc.

Java provides the Character class for checking the type of a character.

MethodPurpose
Character.isLetter(ch)Checks whether ch is a letter.
Character.isDigit(ch)Checks whether ch is a digit.
str.length()Returns the number of characters in the string.
str.charAt(i)Returns the character at index i.

3. Algorithm

  1. Start.
  2. Create a Scanner object.
  3. Accept a complete string using nextLine().
  4. Initialize four counters:
    • letters = 0
    • spaces = 0
    • digits = 0
    • others = 0
  5. Repeat for every character in the string:
    • Obtain the character using str.charAt(i).
    • If it is a letter, increment letters.
    • Else if it is a digit, increment digits.
    • Else if it is a blank space, increment spaces.
    • Otherwise, increment others.
  6. Display the four counts.
  7. Stop.

4. Java Program

Using the Character Class

import java.util.Scanner;

public class CountCharacters {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a string: ");

        String str = sc.nextLine();

        int letters = 0;
        int spaces = 0;
        int digits = 0;
        int others = 0;

        for (int i = 0; i < str.length(); i++) {

            char ch = str.charAt(i);

            if (Character.isLetter(ch)) {
                letters++;
            }
            else if (Character.isDigit(ch)) {
                digits++;
            }
            else if (ch == ' ') {
                spaces++;
            }
            else {
                others++;
            }
        }

        System.out.println("Letters : " + letters);
        System.out.println("Spaces  : " + spaces);
        System.out.println("Digits  : " + digits);
        System.out.println("Others  : " + others);

        sc.close();
    }
}

Output

Enter a string: Hello World 123!

Letters : 10
Spaces  : 2
Digits  : 3
Others  : 1

5. Understanding the Important Statements

1. Reading the String

String str = sc.nextLine();

nextLine() reads the complete line, including spaces.

For example:

Hello World 123

is read as one complete string.

If we use:

sc.next()

only Hello would be read because next() stops when it encounters whitespace.

2. Finding the Length

str.length()

returns the total number of characters in the string.

For example:

String str = "Hello";

then:

str.length()

returns:

5

3. Accessing a Character

str.charAt(i)

returns the character at index i.

For example:

String str = "Hello";
IndexCharacter
0H
1e
2l
3l
4o

Therefore:

str.charAt(0)

returns H.

4. Checking for a Letter

Character.isLetter(ch)

returns true if the character is a letter.

For example:

Character.isLetter('A')

returns:

true

5. Checking for a Digit

Character.isDigit(ch)

returns true if the character is a digit.

For example:

Character.isDigit('5')

returns:

true

6. Checking for a Space

A single character is written using single quotation marks: 

ch == ' '

Do not write:

ch == " "

because " " is a String, whereas ' ' is a char.

6. How the Program Works

Suppose the user enters:

Hello World 123!

The program examines each character one by one.

Character TypeExamplesCounter
LettersH, e, l, l, o, W, o, r, l, d10
SpacesBlank spaces2
Digits1, 2, 33
Other Characters!1

The program maintains four separate counters and increments the appropriate counter whenever a character belongs to that category.

7. Result

The Java program to count letters, spaces, digits, and other characters in a user-entered string was successfully implemented using the Scanner class, String methods, Character class, conditional statements, and a for loop.

8. Conclusion

In this practical, we learned how to accept a complete string from the user using nextLine() and examine each character using charAt().

We also learned how to use Character.isLetter() and Character.isDigit() to identify character types, and how to use counters to calculate the number of letters, spaces, digits, and other characters in a string.
