Practical No. 9

Demonstration of Constructors and Object Cleanup in Java

1. Aim

To write a Java program to demonstrate default, parameterized, and overloaded constructors using the this keyword and understand the concept of object cleanup in Java.

2. Theory

A constructor is a special method that is automatically called when an object is created.

Types of Constructors

  1. Default/No-argument constructor – takes no arguments.
  2. Parameterized constructor – takes arguments to initialize an object.
  3. Overloaded constructors – multiple constructors with different parameter lists.

The this keyword refers to the current object. It can also be used for constructor chaining, such as this("Unknown", 0).

Java does not have a destructor like C++. Objects that are no longer reachable are automatically handled by the Garbage Collector (GC). Explicit cleanup methods can be used when required. The old finalize() mechanism should not be used for normal cleanup.

3. Algorithm

  1. Start the program.
  2. Define a Student class with name, rollNo, and object count.
  3. Define a no-argument constructor using this.
  4. Define a parameterized constructor to initialize student details.
  5. Create three student objects.
  6. Display the details of all objects.
  7. Display the number of created objects.
  8. Perform explicit cleanup for one object.
  9. Set one reference to null to demonstrate garbage-collection eligibility.
  10. Display the final message and stop.

5. Java Program 

class Student {

    String name;
    int rollNo;
    static int count = 0;

    // No-argument constructor
    Student() {
        this("Unknown", 0);
        System.out.println("No-argument constructor used");
    }

    // Parameterized constructor
    Student(String name, int rollNo) {
        this.name = name;
        this.rollNo = rollNo;
        count++;

        System.out.println(
            "Constructor called for: " + name
        );
    }

    // Display student details
    void display() {
        System.out.println(
            "Name: " + name + ", Roll No: " + rollNo
        );
    }

    // Explicit cleanup method
    void cleanup() {
        if (count > 0) {
            count--;
        }

        System.out.println(
            "Cleanup performed for: " + name
        );
    }
}

public class ConstructorDemo {

    public static void main(String[] args) {

        // Creating objects
        Student s1 = new Student();
        Student s2 = new Student("Parmeshwar", 101);
        Student s3 = new Student("Aarti", 102);

        // Display details
        System.out.println("\nStudent Details:");

        s1.display();
        s2.display();
        s3.display();

        // Display object count
        System.out.println(
            "\nNumber of objects = " + Student.count
        );

        // Explicit cleanup
        s3.cleanup();

        System.out.println(
            "Objects after cleanup = " + Student.count
        );

        // Object becomes eligible for garbage collection
        s1 = null;

        System.out.println(
            "\ns1 is now null and its object may be "
            + "eligible for garbage collection."
        );
    }
}

6. Program Explanation

6.1 Student Class

The Student class contains the student name, roll number, and a static variable count to keep track of the number of created objects.

6.2 No-Argument Constructor

The no-argument constructor does not directly initialize the values. Instead, it uses this("Unknown", 0) to call the parameterized constructor.

This is an example of constructor chaining.

6.3 Parameterized Constructor

The parameterized constructor accepts the student's name and roll number and initializes the corresponding instance variables.

The this keyword is used to distinguish the instance variables from the constructor parameters.

6.4 Object Creation

Three Student objects are created using different constructor calls.

  • s1 uses the no-argument constructor.
  • s2 uses the parameterized constructor.
  • s3 uses the parameterized constructor.

6.5 Explicit Cleanup

The cleanup() method demonstrates explicit cleanup for one object and decreases the object count.

6.6 Garbage Collection Eligibility

When s1 is assigned null, the object previously referenced by s1 becomes eligible for garbage collection if no other reference points to it.

9. Key Points to Remember

  • A constructor is automatically called when an object is created.
  • A no-argument constructor does not take parameters.
  • A parameterized constructor accepts values during object creation.
  • Multiple constructors with different parameter lists demonstrate constructor overloading.
  • The this keyword refers to the current object.
  • this() can be used for constructor chaining.
  • Java does not use destructors like C++.
  • Objects that are no longer reachable may become eligible for garbage collection.
  • Explicit cleanup methods can be used when required.
  • The old finalize() mechanism should not be used for normal cleanup.
