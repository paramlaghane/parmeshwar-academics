Experiment No. 9

Class Demonstrating Constructor and Destructor

Aim

Design a Java class that demonstrates:

  1. Constructors — default, parameterized, and overloaded using the this keyword.
  2. “Destructor” behaviour — since Java has no destructor, demonstrate the cleanup method, finalize method, and AutoCloseable / try-with-resources approach.

Theory

A constructor is a special member method that runs automatically when an object is created using new. It is used to initialize the object's fields.

A constructor:

  • Has the same name as the class.
  • Has no return type, not even void.
  • Runs automatically when an object is created using new.

The constructors demonstrated are:

  • Default constructor – creates an object with default values.
  • Parameterized constructor – creates and initializes an object in one step.
  • Overloaded constructors – provide different ways to create objects.

The this keyword is used to refer to the current object and for constructor chaining.

Java has no destructor. Unlike C++, Java uses garbage collection. The finalize method is not reliable because the garbage collector may run late or never. System.gc() is only a request to the JVM.

A cleanup / close method provides deterministic cleanup. AutoCloseable with try-with-resources provides automatic and deterministic cleanup.

Algorithm 

CLASS Student:
    Fields: name, rollNo, static count

    CONSTRUCTOR Student():
        call Student("Unknown", 0)

    CONSTRUCTOR Student(name, rollNo):
        this.name = name
        this.rollNo = rollNo
        count = count + 1
        PRINT "Constructor called: object created"

    METHOD display():
        PRINT name and rollNo

    METHOD cleanup():
        count = count - 1
        PRINT "Cleanup done"

    METHOD finalize():
        PRINT "finalize() called"

MAIN:
    1. Start
    2. Create object with default constructor
    3. Create two objects with parameterized constructor
    4. Display all three objects and live object count
    5. Call cleanup() on one object
    6. Set a reference to null and request System.gc()
    7. Stop

Program 

class Student {
    String name;
    int rollNo;
    static int count = 0;

    // Default constructor
    Student() {
        this("Unknown", 0);
        System.out.println(
            "  (default constructor used)"
        );
    }

    // Parameterized constructor
    Student(String name, int rollNo) {
        this.name = name;
        this.rollNo = rollNo;
        count++;

        System.out.println(
            "Constructor called: object created -> " + name
        );
    }

    // Display student details
    void display() {
        System.out.println(
            "  Name: " + name + ", Roll No: " + rollNo
        );
    }

    // Cleanup method
    void cleanup() {
        count--;

        System.out.println(
            "Cleanup done for: " + name
        );
    }

    // Legacy finalize() method
    @Override
    protected void finalize() {
        System.out.println(
            "finalize() called by GC for: " + name
        );
    }
}

public class ConstructorDemo {
    public static void main(String[] args) {

        System.out.println("--- Creating objects ---");

        Student s1 = new Student();
        Student s2 = new Student("Parmeshwar", 101);
        Student s3 = new Student("Aarti", 102);

        System.out.println("\n--- Displaying objects ---");

        s1.display();
        s2.display();
        s3.display();

        System.out.println(
            "\nLive objects = " + Student.count
        );

        System.out.println(
            "\n--- Manual cleanup (the 'destructor' role) ---"
        );

        s3.cleanup();

        System.out.println(
            "Live objects after cleanup = "
            + Student.count
        );

        System.out.println(
            "\n--- Requesting garbage collection ---"
        );

        s1 = null;

        System.gc();

        System.out.println("End of main()");
    }
}
