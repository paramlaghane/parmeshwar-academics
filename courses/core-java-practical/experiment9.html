Experiment No. 9

Class Demonstrating Constructor and Destructor

Aim

To design a Java class that demonstrates default and parameterized constructors, constructor chaining using the this keyword, and the concept of object cleanup in Java.

Theory

A constructor is a special method that is automatically called when an object is created using new.

  • A constructor has the same name as the class.
  • It has no return type.
  • A default constructor takes no arguments.
  • A parameterized constructor takes arguments to initialize an object.
  • The this keyword refers to the current object and can also be used for constructor chaining.

Java does not have a destructor like C++. Objects that are no longer referenced may be handled by the Garbage Collector. The cleanup() method demonstrates explicit cleanup, while finalize() demonstrates the traditional garbage-collection concept.

Algorithm

  1. Start.
  2. Define the Student class with name and rollNo.
  3. Define a default constructor using this.
  4. Define a parameterized constructor.
  5. Define methods to display details and perform cleanup.
  6. Create three Student objects.
  7. Display the details of all objects.
  8. Call the cleanup() method for one object.
  9. Set one object reference to null and request garbage collection.
  10. Stop.

Program

class Student {
    String name;
    int rollNo;

    // Default constructor
    Student() {
        this("Unknown", 0);
    }

    // Parameterized constructor
    Student(String name, int rollNo) {
        this.name = name;
        this.rollNo = rollNo;
    }

    // Display details
    void display() {
        System.out.println(name + " - " + rollNo);
    }

    // Cleanup method
    void cleanup() {
        System.out.println("Cleanup done for " + name);
    }

    // finalize method
    protected void finalize() {
        System.out.println("finalize() called for " + name);
    }
}

public class ConstructorDemo {
    public static void main(String[] args) {

        Student s1 = new Student();
        Student s2 = new Student("Parmeshwar", 101);
        Student s3 = new Student("Aarti", 102);

        s1.display();
        s2.display();
        s3.display();

        s3.cleanup();

        s1 = null;
        System.gc();
    }
}

Result

The Java program successfully demonstrates constructors, constructor chaining using this, object initialization, cleanup, and the concept of garbage collection.
