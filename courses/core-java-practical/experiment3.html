Java Programs to Calculate the Area and Perimeter (Circumference) of a Circle

Java Programs to Calculate the Area and Perimeter (Circumference) of a Circle

1. Aim

To write, compile, execute, and test Java programs that calculate the area and perimeter (circumference) of a circle using progressively richer Java features such as arithmetic operations, predefined constants, keyboard input, and object-oriented programming concepts.

2. Formula Used

Area of Circle 


Area = π × r × r

Circumference (Perimeter) 


Perimeter = 2 × π × r

where

  • π = 3.141592653589793 (Math.PI)
  • r = Radius of the circle

3. Introduction

A circle is a two-dimensional geometric figure defined by its radius. In Java, the predefined constant Math.PI provides an accurate value of π for mathematical calculations.

In this practical, we calculate both the area and the perimeter (circumference) of a circle. The first program accepts the radius from the keyboard using the Scanner class, while the second program introduces object-oriented programming concepts using a user-defined class.

4. Program 1 – Using Scanner for User Input

Aim

To write a Java program that accepts the radius from the keyboard and calculates the area and perimeter of the circle.

Algorithm

  1. Start the program.
  2. Import the Scanner class.
  3. Create a Scanner object.
  4. Accept the radius from the user.
  5. Calculate the area.
  6. Calculate the perimeter.
  7. Display the results.
  8. Close the scanner.
  9. Stop the program.

Program 


import java.util.Scanner;

public class CircleDemo {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter radius of the circle: ");
        double r = sc.nextDouble();

        double area = Math.PI * r * r;
        double perimeter = 2 * Math.PI * r;

        System.out.println("Area of the circle = " + area);
        System.out.println("Perimeter of the circle = " + perimeter);

        sc.close();
    }
}

Sample Output 


Enter radius of the circle: 10

Area of the circle = 314.1592653589793
Perimeter of the circle = 62.83185307179586

Explanation

  • import java.util.Scanner; imports the Scanner class.
  • Scanner sc = new Scanner(System.in); creates an object to read keyboard input.
  • nextDouble() reads a decimal number entered by the user.
  • Math.PI is used for accurate calculations.
  • area = Math.PI * r * r; calculates the area of the circle.
  • perimeter = 2 * Math.PI * r; calculates the circumference (perimeter).
  • sc.close(); releases the resources used by the Scanner object.

5. Program 2 – Using a User-Defined Class

Aim

To write a Java program that defines a Circle class with data members and methods to calculate the area and perimeter of a circle.

Algorithm

  1. Create a class named Circle.
  2. Declare a data member radius.
  3. Create a constructor to initialize the radius.
  4. Create methods to calculate the area and perimeter.
  5. Create an object of the Circle class.
  6. Call the methods and display the results.
  7. Stop the program.

Program 


class Circle {

    double radius;

    Circle(double radius) {
        this.radius = radius;
    }

    double calculateArea() {
        return Math.PI * radius * radius;
    }

    double calculatePerimeter() {
        return 2 * Math.PI * radius;
    }
}

public class CircleDemo {

    public static void main(String[] args) {

        Circle c = new Circle(10);

        System.out.println("Radius = " + c.radius);
        System.out.println("Area = " + c.calculateArea());
        System.out.println("Perimeter = " + c.calculatePerimeter());
    }
}

Output 


Radius = 10.0
Area = 314.1592653589793
Perimeter = 62.83185307179586

Explanation

  • Circle is a user-defined class.
  • The constructor initializes the radius of the object.
  • The keyword this refers to the current object.
  • The methods calculateArea() and calculatePerimeter() perform the required calculations.
  • An object of the Circle class is created using the new keyword.
  • This program introduces the object-oriented programming concepts covered in Unit 2.

8. Key Points to Remember

  • Math.PI provides an accurate value of π.
  • The double data type is suitable for decimal arithmetic.
  • The Scanner class is used for accepting user input.
  • Always close the Scanner object after use.
  • A constructor initializes an object when it is created.
  • The this keyword refers to the current object.
  • The new keyword creates an object in memory.
  • Methods help organize code and improve reusability.

9. Conclusion

We used the double data type for decimal arithmetic, the predefined constant Math.PI for accurate calculations, and the Scanner class for accepting keyboard input. Finally, we implemented the solution using a user-defined Circle class with a constructor and methods, introducing the fundamental concepts of object-oriented programming in Java.
