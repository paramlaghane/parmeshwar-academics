Star Pattern Programs Using Nested for Loops

Star Pattern Programs Using Nested for Loops

1. Aim

To write, compile, execute, and test Java programs that use nested for loops to display various star (*) patterns on the screen.

2. Introduction

Nested for loops are widely used in Java to solve problems that involve rows and columns. In pattern programming, the outer loop controls the number of rows, while the inner loop controls the number of symbols printed in each row.

By changing the starting value, ending value, or direction of the loops, different patterns such as rectangles, triangles, pyramids, and diamonds can be generated. Pattern programs are an excellent way to understand nested loops and logical thinking.

3. Program 1 – Solid Rectangle of Stars

Aim

Display a 5 × 5 rectangle of stars.

Algorithm

  1. Start the program.
  2. Declare two variables: rows = 5 and cols = 5.
  3. Use an outer loop to print each row.
  4. Use an inner loop to print five stars in each row.
  5. After printing one row, move to the next line.
  6. Repeat until all rows are printed.
  7. Stop the program.

Program 


public class Pattern1Rectangle {

    public static void main(String[] args) {

        int rows = 5;
        int cols = 5;

        for (int i = 1; i <= rows; i++) {

            for (int j = 1; j <= cols; j++) {
                System.out.print("* ");
            }

            System.out.println();
        }
    }
}

Output 


* * * * *
* * * * *
* * * * *
* * * * *
* * * * *

Explanation

  • The outer loop executes five times, producing five rows.
  • The inner loop executes five times for each row, printing five stars.
  • System.out.print() prints stars on the same line.
  • System.out.println() moves the cursor to the next line after each row.
  • Since both loops execute five times, a 5 × 5 solid rectangle is displayed.

4. Program 2 – Left-Aligned Right-Angled Triangle

Aim

Display a right-angled triangle in which row i contains i stars.

Algorithm

  1. Start the program.
  2. Declare n = 5.
  3. Use an outer loop from 1 to n.
  4. Use an inner loop from 1 to the current row number.
  5. Print "* " in each iteration.
  6. Move to the next line after each row.
  7. Stop the program.

Program 


public class Pattern2RightTriangle {

    public static void main(String[] args) {

        int n = 5;

        for (int i = 1; i <= n; i++) {

            for (int j = 1; j <= i; j++) {
                System.out.print("* ");
            }

            System.out.println();
        }
    }
}

Output 


*
* *
* * *
* * * *
* * * * *

Explanation

  • The outer loop controls the number of rows.
  • The inner loop prints stars.
  • The condition j <= i causes the number of stars to increase with each row.
  • As the row number increases, the triangle becomes wider.

5. Program 3 – Inverted Right-Angled Triangle

Aim

Display an inverted right-angled triangle.

Algorithm

  1. Start the program.
  2. Declare n = 5.
  3. Use an outer loop from n down to 1.
  4. Use an inner loop from 1 to the current row number.
  5. Print "* " in each iteration.
  6. Move to the next line after each row.
  7. Stop the program.

Program 


public class Pattern3InvertedTriangle {

    public static void main(String[] args) {

        int n = 5;

        for (int i = n; i >= 1; i--) {

            for (int j = 1; j <= i; j++) {
                System.out.print("* ");
            }

            System.out.println();
        }
    }
}

Output 


* * * * *
* * * *
* * *
* *
*

Explanation

  • The outer loop executes in reverse order, from 5 down to 1.
  • The inner loop prints stars equal to the current row number.
  • Each successive row contains one fewer star than the previous row.
  • Changing only the direction of the outer loop converts the right-angled triangle into an inverted triangle.

6. Summary of Pattern Programs

The three programs in this practical demonstrate how nested for loops can be used to generate different star patterns. In every program, the outer loop controls the number of rows, while the inner loop controls the number of stars printed in each row.

Program Outer Loop Inner Loop Pattern Produced
Program 1 1 to 5 1 to 5 Solid Rectangle
Program 2 1 to 5 1 to current row Right-Angled Triangle
Program 3 5 down to 1 1 to current row Inverted Triangle

7. Key Points to Remember

  • The outer loop determines the number of rows.
  • The inner loop determines the number of stars printed in each row.
  • Changing the loop limits changes the pattern.
  • System.out.print() prints output on the same line.
  • System.out.println() moves the cursor to the next line.
  • Nested loops are commonly used for pattern printing, matrices, and two-dimensional data processing.

8. Conclusion

In this practical, we successfully used nested for loops to generate three different star patterns: a solid rectangle, a left-aligned right-angled triangle, and an inverted right-angled triangle. The practical demonstrates how the outer loop controls the rows, while the inner loop controls the number of stars printed in each row. By modifying loop conditions, different patterns can be created, strengthening the understanding of nested loops and logical program design in Java.
