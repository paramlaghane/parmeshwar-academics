Practical No. 10

Program to Implement Single-Level Inheritance

Aim

To write a Java program to demonstrate single-level inheritance, where one subclass inherits the properties and methods of a superclass.

Theory

Inheritance is an important feature of Object-Oriented Programming that allows a new class to acquire the properties and methods of an existing class.

In single-level inheritance, there is one superclass and one subclass. 

Superclass
    ↓
Subclass

In Java, inheritance is implemented using the extends keyword.

Algorithm

  1. Start.
  2. Create a superclass Vehicle with a field and method.
  3. Create a subclass Car using extends Vehicle.
  4. Add a field and method to the Car class.
  5. Create an object of Car.
  6. Access the inherited field and method.
  7. Call the subclass method.
  8. Display the output.
  9. Stop.

Program 

// Superclass
class Vehicle {
    String brand = "Toyota";

    void start() {
        System.out.println("Vehicle starts");
    }
}

// Subclass
class Car extends Vehicle {
    int wheels = 4;

    void drive() {
        System.out.println("Car drives on " + wheels + " wheels");
    }
}

// Main class
public class SingleInheritanceDemo {
    public static void main(String[] args) {

        Car c = new Car();

        // Inherited members
        System.out.println("Brand: " + c.brand);
        c.start();

        // Subclass member
        c.drive();
    }
}

Output 

Brand: Toyota
Vehicle starts
Car drives on 4 wheels

Result

The Java program successfully demonstrates single-level inheritance using the extends keyword.
