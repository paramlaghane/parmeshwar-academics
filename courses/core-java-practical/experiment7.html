Practical No. 07

Sum of Digits in a Character Array

1. Aim

To write a Java program containing a function (method) that accepts a character array as a parameter and returns the sum of all digit characters present in the array.

Non-digit characters should be ignored.

2. Theory

A character array is an array that stores individual characters. In Java, a character array is declared using the char[] data type. 


char[] data = {'1', '2', '3', 'a', ' ', '9'};

In this practical, the program examines every character in the array and checks whether it is a digit.

Java provides the Character.isDigit() method to check whether a character represents a digit.

When a digit character is found, it is converted into its numeric value using: 


ch - '0'

The numeric value is then added to a variable named sum.

3. Algorithm

Method: sumOfDigits(arr)

  1. Start.
  2. Set sum = 0.
  3. Traverse every element of the character array.
  4. Store the current character in ch.
  5. Check whether ch is a digit.
  6. If it is a digit:
    • Convert it into its numeric value using ch - '0'.
    • Add the value to sum.
  7. Ignore non-digit characters.
  8. Return sum.

Main Program

  1. Create a character array.
  2. Pass the array to sumOfDigits().
  3. Store the returned value in result.
  4. Display the array.
  5. Display the calculated sum.
  6. Stop.

4. Java Program 


public class SumOfDigits {

    // Method to calculate the sum of digit characters
    static int sumOfDigits(char[] arr) {

        int sum = 0;

        for (int i = 0; i < arr.length; i++) {

            char ch = arr[i];

            if (Character.isDigit(ch)) {

                sum = sum + (ch - '0');

            }

        }

        return sum;

    }


    public static void main(String[] args) {

        char[] data = {'1', '2', '3', 'a', ' ', '9'};

        int result = sumOfDigits(data);

        System.out.print("Array: ");

        for (char ch : data) {

            System.out.print("[" + ch + "] ");

        }

        System.out.println();

        System.out.println("Sum of digits = " + result);

    }

}

Sample Output 


Array: [1] [2] [3] [a] [ ] [9]

Sum of digits = 15

5. Program Explanation

1. Creating the Character Array 


char[] data = {'1', '2', '3', 'a', ' ', '9'};

The array contains six characters: 


1   2   3   a   [space]   9

Only 1, 2, 3, and 9 are digits.

2. Calling the Method 


int result = sumOfDigits(data);

The array data is passed to the method.

The method calculates: 


1 + 2 + 3 + 9 = 15

and returns 15.

Therefore: 


result = 15

3. Accessing Array Elements

Inside the method: 


char ch = arr[i];

gets one character from the array at a time.

For a character array, we use: 


arr.length

Notice that there are no parentheses.

This is different from a String: 


str.length()

because String.length() is a method, whereas an array's length is a field.

4. Checking for a Digit 


if (Character.isDigit(ch))

checks whether the current character is a digit.

For example:

Character Result
'5' true
'9' true
'a' false
'@' false
' ' false

5. Converting the Character 


ch - '0'

converts a digit character to its numeric value.

For example: 


'1' - '0' = 1

'2' - '0' = 2

'9' - '0' = 9

The converted value can then be added to sum.

6. Returning the Result 


return sum;

sends the calculated sum back to the statement that called the method. 


int result = sumOfDigits(data);

6. Step-by-Step Working

The character array is: 


{'1', '2', '3', 'a', ' ', '9'}

The program examines each character one by one.

Character Is Digit? Numeric Value Sum
'1' Yes 1 1
'2' Yes 2 3
'3' Yes 3 6
'a' No Ignored 6
' ' No Ignored 6
'9' Yes 9 15

Therefore, the final value of sum is: 


15

7. Hand Calculation

The array is: 


{'1', '2', '3', 'a', ' ', '9'}

Digit characters are: 


'1'   '2'   '3'   '9'

Their numeric values are: 


1 + 2 + 3 + 9 = 15

Therefore: 


Sum of digits = 15

The characters 'a' and ' ' are ignored because they are not digits.

8. Important Concepts

Concept Explanation
char[] Used to create an array of characters.
arr.length Returns the number of elements in the character array.
arr[i] Accesses the character at index i.
Character.isDigit(ch) Checks whether the character is a digit.
ch - '0' Converts a digit character into its numeric value.
return sum Returns the calculated sum to the calling statement.

9. Result

The Java program to calculate the sum of all digit characters in a character array was successfully implemented using a user-defined method, character array traversal, Character.isDigit(), and character-to-integer conversion using ch - '0'.

10. Conclusion

In this practical, we learned how to pass a character array to a user-defined method and return a calculated value from the method.

We also learned how to identify digit characters using Character.isDigit() and convert digit characters into their corresponding numeric values using ch - '0'.

Non-digit characters such as letters, spaces, and symbols are ignored while calculating the sum.
