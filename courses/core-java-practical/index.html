Course Overview

This laboratory course provides practical exposure to Core Java programming through hands-on experiments. Students learn to write, compile, execute, and debug Java programs while developing a strong understanding of object-oriented programming, inheritance, constructors, arrays, strings, and basic problem-solving techniques.

Pre-requisites

  • Knowledge of C or C++ programming is helpful.
  • Basic understanding of programming concepts.
  • Logical thinking and problem-solving ability.
  • Basic computer operating skills.

Course Objectives

  • Learn how to implement object-oriented designs using Java.
  • Understand variables, decision-making, loops, methods, and classes.
  • Develop practical Java programming skills through laboratory exercises.
  • Gain confidence in designing and testing Java applications.

Course Outcomes

  • CO1: Write, compile, execute, and debug Java programs using an IDE.
  • CO2: Validate user input and implement Java programming constructs.
  • CO3: Understand and implement abstract classes and object-oriented concepts.
  • CO4: Design classes, objects, and relationships to solve programming problems.

Laboratory Guidelines

  • Read the experiment carefully before writing the program.
  • Write clean, properly indented, and well-commented Java code.
  • Compile, execute, and test the program with different inputs.
  • Record the algorithm, source code, output, and conclusion in the laboratory journal.
  • Follow object-oriented programming principles and maintain academic integrity.
