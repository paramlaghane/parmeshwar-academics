Reverse a String

Reverse a String

1. Aim

To write, compile, execute, and test a Java program that accepts a string from the user and displays the string in reverse order.

Example


Input  : Java
Output : avaJ

2. Concept: What is a String?

A String is a sequence of characters.

For example, "Java" contains four characters:


J   a   v   a

Each character has an index:

Character J a v a
Index 0 1 2 3

The first character is at index 0, and the last character is at: 


length - 1

Therefore, for "Java":


length = 4
last index = 4 - 1 = 3

3. Important Concept: String Immutability

One of the most important properties of Java strings is: String objects are immutable.

Immutable means that once a String object is created, its contents cannot be changed.

For example:


String str = "Java";

We cannot directly change the existing "Java" object into "avaJ". Instead, we create a new string containing the characters in reverse order.

This is why classes such as StringBuilder and StringBuffer are useful when we need to modify character sequences.

5. Approach — Character Array and Two-Pointer Method

The first approach uses a character array.

Basic Idea

Suppose the input is:


Java

Convert it into:


[J, a, v, a]

Then use two pointers:

  • left → first character
  • right → last character

Swap them:


[J, a, v, a]
 ↓         ↓
left      right

After swapping:

[a, a, v, J]

Move the pointers toward the center and swap again: 


[a, a, v, J]
    ↓   ↓

[a, v, a, J]

Therefore, the reversed string is: avaJ.

6. Algorithm — Character Array Method

  1. Start the program.
  2. Read the string str from the user.
  3. Convert the string into a character array.
  4. Initialize two pointers: 
    
left = 0
right = chars.length - 1
  5. Repeat while left < right.
  6. Swap the characters: 
    
temp = chars[left]
chars[left] = chars[right]
chars[right] = temp
  7. Move the pointers using left++ and right--.
  8. Convert the character array back into a string.
  9. Display the original and reversed strings.
  10. Stop the program.

8. Program — Reverse String Using Character Array

Aim

To write a Java program that reverses a string using a character array and two-pointer swapping.

Program

import java.util.Scanner;

public class ReverseString {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a string: ");
        String str = sc.nextLine();

        // Convert String into a character array
        char[] chars = str.toCharArray();

        // Two pointers
        int left = 0;
        int right = chars.length - 1;

        // Swap characters
        while (left < right) {

            char temp = chars[left];

            chars[left] = chars[right];

            chars[right] = temp;

            left++;
            right--;
        }

        // Convert character array back to String
        String reversed = new String(chars);

        System.out.println("Original : " + str);
        System.out.println("Reversed : " + reversed);

        sc.close();
    }
}

Important

We use:


sc.nextLine();

instead of:


sc.next();

because nextLine() reads the complete line, including spaces.

For example, Hello World is read completely using nextLine(), whereas next() would read only Hello.

10. Important Statements in Program 1

10.1 nextLine()

String str = sc.nextLine();

Reads the complete line entered by the user.

Example:


Input:
Hello World

nextLine() reads:
"Hello World"

Whereas next() would read only:
"Hello"

10.2 toCharArray()

char[] chars = str.toCharArray();

Converts a String into a character array.

For example:


"Java"
   ↓
[J, a, v, a]

This allows us to modify the characters.

10.3 Finding the Last Character

int right = chars.length - 1;

Array indexing starts from 0. Therefore, if the array contains four characters: 


Indexes:
0   1   2   3

Last index:
4 - 1 = 3

Hence, chars.length - 1 gives the last valid index.

10.4 Understanding the Swap

The following code swaps two characters: 

char temp = chars[left];
chars[left] = chars[right];
chars[right] = temp;

Suppose:


chars[left]  = J
chars[right] = a

First:


temp = J

Then:


chars[left] = a

Finally:


chars[right] = J

The result becomes:


a ... J

Why Do We Need temp?

Without temp, the original value of chars[left] would be lost.

11. Key Points to Remember

  • A String is a sequence of characters.
  • String indexing starts from 0.
  • The last valid index is length - 1.
  • String objects are immutable.
  • toCharArray() converts a String into a character array.
  • Two pointers can be used to reverse a character array efficiently.
  • left starts from the beginning and right starts from the end.
  • temp is used to safely swap two characters.
  • nextLine() reads the complete line, including spaces.
  • StringBuilder is mutable and is useful for fast string manipulation.
  • StringBuffer is mutable and thread-safe.
