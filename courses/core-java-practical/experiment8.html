Find the Smallest and Largest Element from an Array

Find the Smallest and Largest Element from an Array

1. Aim

To write, compile, execute, and test a Java program that accepts N numbers, stores them in an array, and finds and displays the smallest and largest elements in the array.

2. Algorithm

Algorithm to Find Smallest and Largest Elements

  1. Start
  2. Read the number of elements n.
  3. Check that n is greater than 0.
  4. Create an integer array arr of size n.
  5. Read n elements into the array.
  6. Set min = arr[0].
  7. Set max = arr[0].
  8. Repeat for i = 1 to n - 1:
    • If arr[i] < min, set min = arr[i].
    • If arr[i] > max, set max = arr[i].
  9. Display min as the smallest element.
  10. Display max as the largest element.
  11. Stop

3. Approach — Assume the First Element

In this approach, the first element of the array is initially assumed to be both the smallest and the largest element. The remaining elements are then compared with these values.

For example:

Array: 45  12  78  3  56

Initially:
min = 45
max = 45

Each remaining element is checked. If an element is smaller than min, it becomes the new minimum. If an element is larger than max, it becomes the new maximum.

4. Java Program

Method: Assume the First Element

import java.util.Scanner;

public class MinMaxArray {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter the number of elements: ");
        int n = sc.nextInt();

        // Validate the array size
        if (n <= 0) {
            System.out.println("Number of elements must be greater than 0.");
            sc.close();
            return;
        }

        int[] arr = new int[n];

        System.out.println("Enter " + n + " elements:");

        // Read array elements
        for (int i = 0; i < n; i++) {
            arr[i] = sc.nextInt();
        }

        // Assume the first element is both minimum and maximum
        int min = arr[0];
        int max = arr[0];

        // Compare remaining elements
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] < min) {
                min = arr[i];
            }

            if (arr[i] > max) {
                max = arr[i];
            }
        }

        System.out.println("Smallest element = " + min);
        System.out.println("Largest element  = " + max);

        sc.close();
    }
}

5. Program Explanation

5.1 Creating the Array

int[] arr = new int[n];

This creates an integer array containing n elements.

For example, if n = 5, then the array has five positions:

Index:   0     1     2     3     4
         ↓     ↓     ↓     ↓     ↓
Array:  [ ]   [ ]   [ ]   [ ]   [ ]

5.2 Reading the Elements

for (int i = 0; i < n; i++) {
    arr[i] = sc.nextInt();
}

The loop reads each number and stores it in the corresponding array position.

5.3 Initializing min and max

int min = arr[0];
int max = arr[0];

The first element is initially assumed to be both the smallest and largest.

Array: 45  12  78  3  56

Initially:
min = 45
max = 45

5.4 Finding the Minimum

if (arr[i] < min) {
    min = arr[i];
}

If the current element is smaller than the current min, the current element becomes the new minimum.

5.5 Finding the Maximum

if (arr[i] > max) {
    max = arr[i];
}

If the current element is larger than the current max, the current element becomes the new maximum.

5.6 Why Are There Two if Statements?

The two comparisons represent two independent questions:

  • Is the current value smaller than min?
  • Is the current value larger than max?

Therefore, using two separate if statements clearly expresses the logic.

8. Key Points to Remember

  • An array stores multiple values of the same data type.
  • Array indexing starts from 0.
  • The first element of the array is arr[0].
  • The last element is at index arr.length - 1.
  • The first element can be used to initialize both min and max.
  • The remaining elements are compared with the current minimum and maximum.
  • Two separate if statements clearly express the minimum and maximum comparisons.
  • The program works with positive, zero, and negative integer values.
  • The array size must be greater than zero.
